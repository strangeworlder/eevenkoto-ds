# Tokens

Live catalog of design tokens that exist in CSS today (color, typography, spacing, radius, line width). **Consume Tier 2 semantics and metrics — never hue primitives.**

This page is the **what exists** gallery. App consume rules are generated into `llms-full.txt` (served at `/llms-full.txt` when Storybook runs). Contributor rules live in `AGENTS.md`. Color tier governance for authors lives under [Color Tokens — Architecture](?path=/docs/foundations-color-tokens-architecture--docs).

```css
/* Correct: semantic intent */
.eevenkoto-card {
  background-color: var(--eevenkoto-color-surface-raised);
  color: var(--eevenkoto-color-content-primary);
  border-color: var(--eevenkoto-color-boundary-subtle);
}
```

## Semantic colors

These are the **consumable** color tokens (Tier 2) currently defined in `tokens.css`. Use them in layouts, utilities, and as Tier 3 bridge fallbacks.

| Domain | Examples | Use for |
| --- | --- | --- |
| `control` | `--eevenkoto-color-control-primary-background` | Buttons, chips, and other contained actions |
| `surface` | `--eevenkoto-color-surface-canvas`, `surface-subtle`, `surface-sunken` | Page canvases, quiet stripes, sunken wells |
| `content` | `--eevenkoto-color-content-primary` | Body text and secondary/disabled copy |
| `boundary` | `--eevenkoto-color-boundary-focus-outer` | Dividers and dual-halo focus rings |
| `depth` | `--eevenkoto-color-depth-shadow-umbra` | Elevation shadows |
| `feedback` | `--eevenkoto-color-feedback-success-background` | Badges and status (subtle + solid) |

## Primitives (internal)

Hue pigments in `primitive-tokens.css`. Tier 2 maps these to semantic roles. **Components and product CSS must never import them.**

<Danger>
  If you are styling a component or page and reach for{' '}
  <code>{'--eevenkoto-color-turquoise-*'}</code>,{' '}
  <code>{'--eevenkoto-color-parchment-*'}</code>, or{' '}
  <code>{'--eevenkoto-color-gold-*'}</code>, stop. Use a Tier 2 semantic token above, or add
  one in <code>tokens.css</code> with a designer.
</Danger>
