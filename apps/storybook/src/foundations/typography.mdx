# Typography

**Related:** [Tokens catalog](?path=/docs/foundations-tokens--docs) · [Minimum-class defaults](?path=/docs/foundations-minimum-class-defaults--docs) · [Typography sample](?path=/docs/core-molecules-typography-sample--docs) · [Prose](?path=/docs/core-molecules-prose--docs) · [Flow](?path=/docs/core-molecules-flow--docs) · [Heading](?path=/docs/core-atoms-heading--docs) · [Paragraph](?path=/docs/core-atoms-paragraph--docs) · [List](?path=/docs/core-molecules-list--docs) · [Caption](?path=/docs/core-atoms-caption--docs)

Type roles and usage for UI. Live size specimens also appear under [Foundations → Tokens → Typography](?path=/docs/foundations-tokens--docs). Color architecture is separate: [Color Tokens](?path=/docs/foundations-color-tokens-architecture--docs).

Typography in Eevenkoto follows the same tier discipline as color: raw optical values live in Tier 1; roles that UI consumes live in Tier 2; component bridges live in Tier 3.

```
┌────────────────────────────────────────────────────────┐
│  Tier 1: Type scale (primitive-tokens.css)             │
│  --eevenkoto-font-size-xs … 3xl                        │
└──────────────────────────┬─────────────────────────────┘
                           │ Mapped to roles
                           ▼
┌────────────────────────────────────────────────────────┐
│  Tier 2: Semantic type & single-tier weights (tokens.css)│
│  heading-*, body-*, caption, control-*, font-weight-*  │
└──────────────────────────┬─────────────────────────────┘
                           │ Consumed by primitives / components
                           ▼
┌────────────────────────────────────────────────────────┐
│  Tier 3: Heading, Paragraph, List, Caption, Button, …  │
│  Private bridges + public override APIs                │
└────────────────────────────────────────────────────────┘
```

## Families

| Token | Face | Use |
| --- | --- | --- |
| `--eevenkoto-font-sans` | Inter | Body, UI controls, H4–H6 headings |
| `--eevenkoto-font-serif` | Outfit | Macro + H3 display headings |

## Heading hierarchy (multi-axis)

Six levels are grouped into three visual tiers. **Do not rely on size alone** — lower levels differentiate via family, case, posture, accent ink, and statblock banding.

| Visual tier | Levels | Primary tools |
| --- | --- | --- |
| **Macro** | H1, H2 | Outfit serif, distinct size jump (`3xl`, `2xl`), bottom rule; H2 uses `content-accent` |
| **Meso** | H3, H4 | H3 Outfit serif (`lg`, `content-primary`); H4 Inter sans semibold (`md`, `content-accent`) |
| **Micro / Statblock** | H5, H6 | H5 Inter sans bold `all-small-caps` (`lg`) on a full-bleed `surface-sunken` band; H6 Inter sans bold italic (`md` = `body-md`, `content-accent`) / run-in |

Details and examples live on [Heading](?path=/docs/core-atoms-heading--docs).

## Font sizes — two tiers

### Tier 1 (scale)

Sparse rem steps in `primitive-tokens.css`: `xs` → `3xl`. These answer “how large is this optical step?” **Never reference Tier 1 sizes from component stylesheets.**

### Tier 2 (semantic)

Role aliases in `tokens.css`. Grammar: `--eevenkoto-font-size-[role]-[variant]`.

| Role | Tokens | Typical consumer |
| --- | --- | --- |
| `heading` | `heading-1` … `heading-6` | Heading primitive (`1`→3xl, `2`→2xl, `3`→lg, `4`→md, `5`→lg, `6`→md) |
| `body` | `body-sm`, `body-md`, `body-lg`, `body-xl` | Paragraph, List, Stat (`lg`), document `body` |
| `caption` | `caption` | Caption primitive, Field hint/error |
| `control` | `control-sm`, `control-md`, `control-lg` | Button, Badge, Chip, Input, Select |

### Component size props (`sm | md | lg`)

Public size props across Button, Paragraph, List, and Badge use the same **`sm | md | lg`** names. Do not reintroduce `small` / `large`. Host CSS may omit `--md` (the base class is already md); framework helpers still emit an explicit `--md` when assembling class strings so the prop API stays aligned across controls.

| Prop value | Typical Tier 2 font role |
| --- | --- |
| `sm` | `control-sm` or `body-sm` |
| `md` | `control-md` or `body-md` (default) |
| `lg` | `control-lg` or `body-lg` |

Themes or density modes can remap a role without renaming the rem ladder.

```css
/* Correct: semantic intent */
.eevenkoto-button {
  font-size: var(--eevenkoto-font-size-control-md);
}

/* Incorrect: Tier 1 scale in a component */
.eevenkoto-button {
  font-size: var(--eevenkoto-font-size-md);
}
```

## Weights

Single-tier face weights in `tokens.css` (consumed directly by components and layouts):

| Token | Value |
| --- | --- |
| `--eevenkoto-font-weight-regular` | `400` |
| `--eevenkoto-font-weight-semibold` | `600` |
| `--eevenkoto-font-weight-bold` | `700` |

Italic bold is loaded for Inter so H6 can use bold italic posture.

## Line heights

| Token | Use |
| --- | --- |
| `--eevenkoto-line-height-tight` | Macro/meso headings, controls |
| `--eevenkoto-line-height-body` | Paragraphs, captions, H4–H6, page body |

## Content color

Pair type with `--eevenkoto-color-content-*` semantic tokens — never hue primitives.

| Role | Token | Typical component |
| --- | --- | --- |
| Body / titles | `content-primary` | Paragraph (default), Heading (H1, H3, H5) |
| Section & feature accents | `content-accent` | Heading (H2, H4, H6), StatblockFeature, AbilityScore label |
| High-emphasis chrome | `content-accent-strong` | Proficient Stat shield, EquipmentBlock emphasis value |
| De-emphasized body | `content-secondary` | Paragraph `--secondary` |
| Metadata / helpers | `content-tertiary` | Caption (default), Field hint |

## Caption vs Paragraph

| Need | Use |
| --- | --- |
| Multi-sentence body or supporting prose | **[Paragraph](?path=/docs/core-atoms-paragraph--docs)** |
| One-line metadata, timestamp, or field helper | **[Caption](?path=/docs/core-atoms-caption--docs)** |
| De-emphasize a full paragraph without making it metadata | Paragraph `tone="secondary"` |
| Quiet ink for Caption | Default (maps to `content-tertiary`) — not Paragraph secondary |

## Usage rules

- Prefer **Heading** for section structure; do not fake titles with bold Paragraph.
- Use **one `h1` per view**; do not skip levels only for visual size.
- Differentiate **H5/H6 with posture, case, and banding**, never a size smaller than `body-md`.
- Limit bottom rules to **macro** headings (H1/H2) and sunken section bands to **H5**.
- Use **Caption** for metadata and helper copy — not for main body text.
- Do not use **Paragraph `sm` + secondary** as a Caption substitute — size and ink roles differ.
- Button label size comes from **`control-*`**, not `body-*`.
