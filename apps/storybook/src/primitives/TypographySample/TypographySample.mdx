# Typography sample

A reading-flow specimen that composes [Flow](?path=/docs/primitives-flow--docs), [Heading](?path=/docs/primitives-heading--docs), [Paragraph](?path=/docs/primitives-paragraph--docs), and [Caption](?path=/docs/primitives-caption--docs) — not a token swatch grid.

Vertical gaps are owned by **Flow** (pair-aware rhythm), not by stacking each primitive’s default margins.

Use it to judge hierarchy, rhythm, and color together: macro rules, meso weight, micro bands and run-ins.
