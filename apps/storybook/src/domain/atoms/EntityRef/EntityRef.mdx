# Entity Ref

An **EntityRef** is an inline pointer to a rules entity (condition, spell, item, …). It **specializes** Core [InlineRef](?path=/docs/core-atoms-inlineref--docs): same chrome (`eevenkoto-inline-ref`), plus Domain `kind` modifiers. It lives in **Domain** because the kind set is product vocabulary. Host alone is **item** (neutral).

In product copy the common form is a real link (`href`) — the same role as eevenko.to `.tooltip-ref`. Pair with [Popover](?path=/docs/core-atoms-popover--docs) + [TooltipCard](?path=/docs/core-molecules-tooltipcard--docs) for previews; the DS does not ship tooltip JS. Drop `.tooltip-ref` and `data-ref-tyyppi` color maps once kinds + InlineRef `locked` / `unlinked` are applied.

## Why to use

Rules prose names other entities constantly. EntityRef marks those names with **kind-colored** ink so readers can tell a referenced term from ordinary words — without Badge chrome or a Button. Prefer bare [InlineRef](?path=/docs/core-atoms-inlineref--docs) when you do not need a closed kind.

## Appearance

### Rest vs hover

At rest the chip **fill and border are transparent**. Kind **ink** (and, for links, a dotted underline) stay visible so the term still reads as a reference. Hover / `:focus-visible` paints the kind background and border.

Motion uses Tier 2 tokens — border on `duration-1`, fill on `duration-3` with `ease-in-out` (same stagger idea as Button).

### Inline flow

Chip padding and border hang outside the glyph via matching negative `margin-inline`, so a normal word space before/after the ref does not look doubled.

## Kinds

The kind set is **closed**. English API names; BEM modifiers are kebab-case.

| Kind (`kind`) | Modifier | Tier 2 source |
| --- | --- | --- |
| `condition` | `--condition` | `feedback-caution` |
| `mechanic` | `--mechanic` | `feedback-info` |
| `classFeature` | `--class-feature` | `feedback-admin` |
| `class` | `--class` | `feedback-info` fill; `feedback-admin` ink / border / underline |
| `spell` | `--spell` | `feedback-info` fill; `control-primary` ink / border / underline |
| `item` (default) | `--item` | `feedback-neutral` (covers gear / varuste / esine) |
| `creature` | `--creature` | `feedback-critical` (covers vastustaja / hirviöpiirre) |

## Links vs plain text

| Form | Markup | Cue |
| --- | --- | --- |
| Link | `<a class="eevenkoto-inline-ref eevenkoto-entity-ref …">` | Dotted underline → solid on hover / focus |
| Tag | `<span class="eevenkoto-inline-ref eevenkoto-entity-ref …">` | Kind ink only (no underline) |

Product entity tooltips should use the **link** form so the preview is extra content on top of navigation, not a substitute for it.

## Migration (eevenko.to)

| Site | Use instead |
| --- | --- |
| `.tooltip-ref` + EntityRef classes | EntityRef host only |
| `[data-ref-tyyppi=vastustaja]` / `hirviöpiirre` | `kind: 'creature'` |
| `[data-ref-tyyppi=varuste]` / `esine` | `kind: 'item'` |
| class name painted as `--class-feature` | `kind: 'class'` |
| `.tooltip-ref-locked` + Lucide lock | `locked` (+ `lockedLabel`) |
| `.unlinked-term` | `unlinked` on InlineRef / EntityRef |

## Anatomy

| Part | Role |
| --- | --- |
| Host (`a` or `span`) | `eevenkoto-inline-ref` + `eevenkoto-entity-ref` + kind modifier |
| `__label` (`eevenkoto-inline-ref__label`) | Visible entity name |

Apps may add `data-ref-id` (or similar) on the host for a TooltipManager-style lookup — that attribute is not part of the DS prop contract.

## Composition with Popover

1. **EntityRef link** — hover / focus target and destination URL.
2. **Popover** (`fixed` + `open`) — portaled panel; app sets `top` / `left`.
3. **TooltipCard** — header / body / footer inside the panel.

See [Popover — Fixed on a link](?path=/docs/core-atoms-popover--docs#fixed-on-a-link-portal-recipe).

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `name` | `string` | — | Visible entity name. |
| `kind` | `EntityRefKind` | `'item'` | Closed kind set. |
| `href` | `string` | — | When set (and not `unlinked`), renders as `<a>`. |
| `unlinked` | `boolean` | `false` | Inherited from InlineRef. |
| `locked` | `boolean` | `false` | Inherited from InlineRef. |
| `lockedLabel` | `string` | `'Locked'` | Inherited from InlineRef. |

### CSS classes

| Class | Role |
| --- | --- |
| `eevenkoto-inline-ref` | Shared Core chrome (always present) |
| `eevenkoto-entity-ref` | Domain marker |
| `eevenkoto-entity-ref--item` … `--spell` | Kind → InlineRef bridge remaps |
| `eevenkoto-inline-ref__label` | Name |

### Type definitions

```ts
export type EntityRefKind =
  | 'condition'
  | 'mechanic'
  | 'classFeature'
  | 'class'
  | 'spell'
  | 'item'
  | 'creature';

export interface EntityRefProps extends InlineRefProps {
  kind?: EntityRefKind;
}
```
