# AbilityName

**AbilityName** is the domain atom for RPG ability names (e.g. *Voimakkuus*, *Ketteryys*, *Sitkeys*, *Älykkyys*, *Viisaus*, *Karisma*, *Sisu*, *Mieli*, *Käsityö*). It renders the full ability name when space permits, and automatically collapses to a 3-letter ALLCAPS abbreviation (e.g. `VOI`, `KET`, `SIS`) when container space is constrained.

Multiple abilities can be composed together with standard conjunctions:
```tsx
<>
  <AbilityName>Voimakkuus</AbilityName> tai <AbilityName>Ketteryys</AbilityName>
</>
```

```html
<span class="eevenkoto-ability-name">
  <span class="eevenkoto-ability-name__full">Voimakkuus</span>
  <span class="eevenkoto-ability-name__short" aria-hidden="true">VOI</span>
</span>
```

## Why to use

Rules text and equipment blocks frequently reference abilities in constrained spaces (such as weapon stat cards or compact tables):
- **Full readability by default:** Displays the full Finnish name (`Voimakkuus`) whenever space permits.
- **Graceful degradation:** When space is cramped (e.g. in multi-column weapon stat cards or mobile screens), collapses automatically to the standard 3-letter abbreviation (`VOI`).
- **Accessible:** Keeps the unabbreviated name in the accessibility tree via visually-hidden text while marking the 3-letter abbreviation `aria-hidden="true"`, so assistive technology reads the full ability name without prohibited ARIA attributes on generic inline spans.

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `name` | `string` | — | Full ability name (e.g. `Voimakkuus` or `Sisu`). |
| `children` | `string \| ReactNode` | — | Alternative to `name` in Core, React, Vue, and Astro (`<AbilityName>Voimakkuus</AbilityName>`). |
| `short` | `string` | `3-letter ALLCAPS` | Optional custom abbreviation override. |
| `variant` | `'auto' \| 'full' \| 'short'` | `'auto'` | Force full or short display, or let container queries respond automatically. |

### CSS classes

| Class | Role |
| --- | --- |
| `eevenkoto-ability-name` | Host container (`span`) |
| `eevenkoto-ability-name__full` | Full name text container |
| `eevenkoto-ability-name__short` | 3-letter uppercase abbreviation container |
| `eevenkoto-ability-name--short` | Modifier forcing short display |
| `eevenkoto-ability-name--full` | Modifier forcing full display |

### Public CSS override tokens

| Token | Purpose |
| --- | --- |
| `--eevenkoto-ability-name-text` | Ability name ink (`inherit` by default) |
