# AbilityScore

**AbilityScore** is one ability **column**: gold label + three [Stat](?path=/docs/core-atoms-stat--docs) chips (arch modifier, disk score, shield save).

For the sandwich panel (header / grid / footer), use **[AbilityScoreGroup](?path=/docs/domain-organisms-abilityscoregroup--docs)**.

## Why to use

Ability columns are decorative and positional (orbiting chips), but still need accessible terms for score / modifier / save. AbilityScore owns that column AT contract.

## When to use

## Anatomy

1. **Root** — `figure.eevenkoto-ability-score`
2. **Label** — `figcaption.eevenkoto-ability-score__label` (serif + `content-accent`)
3. **Stats list** — `dl.eevenkoto-ability-score__stats`
4. **Slots** — modifier (arch, lg), score (disk, sm), save (shield, sm) with visually hidden `dt`s

Chip roles and shapes:

| Role | Shape | Size | Position |
| --- | --- | --- | --- |
| Modifier | `arch` | `lg` | Centered primary figure |
| Score | `disk` | `sm` | Hugs bottom-left of arch |
| Save | `shield` | `sm` | Hugs bottom-right of arch |

## Save proficiency

Default chip borders and ability labels use parchment **`content-accent`**. When `saveProficient` is true, the save shield uses deep gold **`content-accent-strong`** (`eevenkoto-stat--emphasis`) with a thicker border + outline (not color-only). The visually hidden term becomes `{saveLabel} ({proficientLabel})` (defaults `Save (proficient)`).

## Accessibility

- Each column is a `figure` with a `figcaption` ability name and a definition list of score / modifier / save.
- The figcaption has an `id`; the stats `dl` uses `aria-labelledby` so AT announces the ability name with the scores.
- Prefer meaningful `scoreLabel` / `proficientLabel` etc. in the document language.

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `label` | `string` | — | Ability name (column header). |
| `labelId` | `string` | derived | Optional stable id for `aria-labelledby`. |
| `score` | `string` | — | Base score. |
| `modifier` | `string` | — | Modifier (typically signed). |
| `save` | `string` | — | Save bonus (typically signed). |
| `scoreLabel` | `string` | `'Score'` | Visually hidden term. |
| `modifierLabel` | `string` | `'Modifier'` | Visually hidden term. |
| `saveLabel` | `string` | `'Save'` | Visually hidden term. |
| `saveProficient` | `boolean` | `false` | Emphasized shield + proficient suffix in the hidden term. |
| `proficientLabel` | `string` | `'proficient'` | Suffix inside the hidden save term when proficient. |

### CSS classes

| Class | Role |
| --- | --- |
| `eevenkoto-ability-score` | Column root (`figure`) |
| `eevenkoto-ability-score--save-proficient` | Proficient save emphasis |
| `eevenkoto-ability-score__label` | Ability name (`figcaption`) |
| `eevenkoto-ability-score__stats` | Stat definition list |
| `eevenkoto-ability-score__stat` / `--modifier` / `--score` / `--save` | Slot wrappers |
| `eevenkoto-ability-score__stat-label` | Visually hidden `dt` |
| `eevenkoto-ability-score__stat-value` | `dd` around Stat |

| Token | Purpose |
| --- | --- |
