# ContentTable

Table with per-row `readiness` and spanning `locked` rows that carry a Notice. Builds on Table, so columns, variants and stripes work the same.

<Canvas of={ContentTableStories.Default} />

```html
<table class="eevenkoto-table eevenkoto-content-table">
  <thead>
    <tr>
      <th scope="col">Nimi</th>
      <th scope="col">Piiri</th>
    </tr>
  </thead>
  <tbody>
    <tr data-readiness="success">
      <td>Tulipallo</td>
      <td>3. piiri</td>
    </tr>
  </tbody>
</table>
```

<Controls of={ContentTableStories.Default} />

## Why to use

Catalog tables mix available and gated entries. A locked row spans all columns with a Notice, keeping the row/column grid intact instead of faking cells.

## When to use

- Use for spell, item or monster lists where entries differ in readiness or access.
- Use plain Table when no row is gated or flagged.

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `rows` | `ContentTableRow[]` | **required** | Data rows (`readiness`, `attributes`, `cells`) or `{ kind: 'locked', colSpan?, notice }`. |
| `columns` | `TableColumn[]` | **required** | Header columns (`{ key, header, kind? }`), as in [Table](?path=/docs/core-molecules-table--docs). |
| `caption` | `string` | — | Optional `<caption>` copy forwarded to Table. |
| `variant` | `'default' \| 'numeric' \| 'pair'` | `'default'` | Table layout recipe forwarded to Table. |
| `stripe` | `'row' \| 'column' \| 'none'` | `'row'` | Alternating surface band forwarded to Table. |
| `id` | `string` | — | Host `<table id>` (React, Vue, and Astro HTML attributes). |

### Public CSS override tokens

| Token | Purpose |
| --- | --- |
| `--eevenkoto-content-table-edge-width` | Readiness stripe width on the first cell (`line-width-lg`) |
| `--eevenkoto-content-table-edge-color` | Readiness stripe color (`transparent` default; `feedback-success-icon`, `content-accent-strong`, or `boundary-strong` by `data-readiness`) |

## Framework packages

`content-table.css` imports `table.css` and `notice.css` automatically (also import `icon.css` when `locked` rows render Notice icons).

```ts
import '@eevenkoto/css/styles.css';
import '@eevenkoto/css/content-table.css';
import '@eevenkoto/css/icon.css';
import { renderContentTable } from '@eevenkoto/html';

renderContentTable({
  columns: [{ key: 'name', header: 'Nimi' }],
  rows: [{ readiness: 'success', cells: ['Tulipallo'] }],
});
```

```tsx
import '@eevenkoto/css/styles.css';
import '@eevenkoto/css/content-table.css';
import '@eevenkoto/css/icon.css';
import { ContentTable } from '@eevenkoto/react';

<ContentTable
```
