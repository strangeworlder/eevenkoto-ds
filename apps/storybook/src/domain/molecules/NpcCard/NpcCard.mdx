# NpcCard

Compact NPC entry: name, role, divided `details` (PropertyList) and body copy.

<Canvas of={NpcCardStories.Default} />

```html
<article class="eevenkoto-npc-card">
  <header class="eevenkoto-npc-card__header">
    <h3 class="eevenkoto-npc-card__name">Aino Karhu</h3>
    <p class="eevenkoto-npc-card__role">Kauppias</p>
  </header>
  <dl class="eevenkoto-property-list eevenkoto-property-list--divided">
    <div class="eevenkoto-property">
      <dt class="eevenkoto-property__label">Asenne</dt>
      <dd class="eevenkoto-property__value">Ystävällinen</dd>
    </div>
  </dl>
  <div class="eevenkoto-npc-card__body eevenkoto-prose">
    <p>Tuntee vanhat kauppareitit.</p>
  </div>
</article>
```

<Controls of={NpcCardStories.Default} />

## Why to use

NPC entries recur in adventures. A shared structure gives consistent heading levels (outline-safe) and a divided details list.

## When to use

- Use for single NPC entries or compose several in NpcCardGrid.
- Use Statblock for full combat stats.

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `name` / `nameHtml` | `string` | — | NPC name (`name` required unless `nameHtml` is passed; `nameHtml` is sanitized inline HTML). |
| `nameLevel` | `2 \| 3 \| 4` | `3` | Semantic heading level (`line-height-snug`). |
| `role` / `roleHtml` | `string` | — | Role / epithet line below the name. |
| `details` | `PropertyItem[]` | — | Divided PropertyList rows (`details`, never `traits`). |
| `body` / `bodyHtml` | `string` | — | Plain-text or trusted HTML description copy. |
| `id` | `string` | — | Host `<article id>`. |

### Public CSS override tokens

| Token | Purpose |
| --- | --- |
| `--eevenkoto-npc-card-bg` | Card fill (`surface-raised`) |
| `--eevenkoto-npc-card-border-color` | Card border (`boundary-subtle`) |
| `--eevenkoto-npc-card-border-width` | Card border width (`line-width-sm`) |
| `--eevenkoto-npc-card-role-color` | Role subtitle ink (`content-secondary`) |

## Framework packages

`npc-card.css` imports `heading.css`, `property.css`, and `prose.css` automatically.

```ts
import '@eevenkoto/css/styles.css';
import '@eevenkoto/css/npc-card.css';
import { renderNpcCard } from '@eevenkoto/html';

renderNpcCard({
  name: 'Aino Karhu',
  role: 'Kauppias',
  details: [{ label: 'Asenne', value: 'Ystävällinen' }],
});
```

```tsx
import '@eevenkoto/css/styles.css';
import '@eevenkoto/css/npc-card.css';
import { NpcCard } from '@eevenkoto/react';

<NpcCard
  name="Aino Karhu"
  role="Kauppias"
  details={[{ label: 'Asenne', value: 'Ystävällinen' }]}
/>
```

```vue
<script setup>
import '@eevenkoto/css/styles.css';
import '@eevenkoto/css/npc-card.css';
import { NpcCard } from '@eevenkoto/vue';

</script>

<template>
  <NpcCard name="Aino Karhu" role="Kauppias" :details="details" />
</template>
```
