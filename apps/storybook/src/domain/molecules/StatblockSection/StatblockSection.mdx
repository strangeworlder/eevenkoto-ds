# StatblockSection

**StatblockSection** is the section molecule: a semantic **H2** title plus a stack of [StatblockFeature](?path=/docs/domain-molecules-statblockfeature--docs) entries. Visual weight for the title matches meso H3 (no macro bottom rule).

<Canvas of={StatblockSectionStories.Default} />

```html
<section class="eevenkoto-statblock-section">
  <h2 class="eevenkoto-heading eevenkoto-heading--2 eevenkoto-heading--primary">Toiminnot</h2>
  <div class="eevenkoto-statblock-feature">…</div>
  <div class="eevenkoto-statblock-feature">…</div>
</section>
```

### Playground

Use story args in the Canvas controls where available; the default story shows a typical Actions block.

## Why to use

Grouping features under a real H2 keeps the outline contiguous under the creature H1 and gives a clear landmark for Actions, Reactions, Legendary Actions, and similar clusters.

## When to use

## Anatomy

1. **Root** — `section.eevenkoto-statblock-section`
2. **Title** — `h2.eevenkoto-heading--2` (visual remap → meso H3)
3. **Features** — one or more `.eevenkoto-statblock-feature` children

## Visual remap

Inside `.eevenkoto-statblock-section`, the H2 drops macro chrome:

| Axis | Override |
| --- | --- |
| Color | `--eevenkoto-color-content-primary` |
| Size | `--eevenkoto-font-size-heading-3` |
| Family / weight | Serif bold |
| Border | None (no macro rule) |
| Margin | Compact (`space-2` start) |

Gap between title and features uses `--eevenkoto-statblock-section-gap` (default `--eevenkoto-space-3`).

## Accessibility

- Section landmark is a real `<section>` with an H2 title.
- Feature children must be H3 (via StatblockFeature) — do not insert bare paragraphs as “named” entries.
- One section title per cluster; avoid multiple H2s that repeat the same label.

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `title` | `string` | — | Section heading (H2). |
| `features` | `StatblockFeatureProps[]` | — | Stacked feature entries. |

```ts
export interface StatblockSectionProps {
  title: string;
  features: StatblockFeatureProps[];
}
```
