# LicenseBar

Legal-license strip. `edge` placement is a fixed vertical stripe on the inline-end viewport edge; `inline` renders a plain row. Only the entry for `activeLicense` is visible.

<Canvas of={LicenseBarStories.Proprietary} />

<Controls of={LicenseBarStories.Proprietary} />

## Why to use

Which license a reading mode falls under is legal information that must be visible and consistent. The strip pairs a neutral readable surface with a thick hue edge (accent for proprietary, primary for open), so contrast never depends on a coloured fill.

## When to use

- Use once per page to show the active content license and legal links.
- Provide one entry per license; the active one is shown and the rest are `hidden`.
- Use `placement="inline"` inside content or in print-oriented layouts; the `edge` stripe is hidden in print.

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `id` | `string` | — | Element `id` on `<aside>`. |
| `activeLicense` | `'proprietary' \| 'open'` | `'proprietary'` | Visible entry; `'open'` recolours the stripe (`eevenkoto-license-bar--open`). |
| `placement` | `'edge' \| 'inline'` | `'edge'` | Fixed vertical viewport stripe vs static inline row. |
| `entries` | `LicenseBarEntry[]` | **required** | License + links per mode (`{ license, links }`). |
| `separator` | `string` | `' · '` | Text separator between links. |
| `ariaLabel` | `string` | `'License'` | Accessible landmark name for the `<aside>`. |

### Public CSS override tokens

| Token | Purpose |
| --- | --- |
| `--eevenkoto-license-bar-bg` | Edge stripe background (`surface-raised`) |
| `--eevenkoto-license-bar-text` | Separator/copy ink (`content-primary`) |
| `--eevenkoto-license-bar-link-color` | License link ink (`link-default`) |
| `--eevenkoto-license-bar-edge-color` | Accent edge stripe (`content-accent-strong`, or `control-primary-background` in `--open`) |
| `--eevenkoto-license-bar-edge-width` | Accent edge stripe thickness (`line-width-lg`) |
| `--eevenkoto-license-bar-size` | Edge stripe cross-axis width (`2rem`, `1.4rem` on narrow viewports) |

## Framework packages

```ts
import '@eevenkoto/css/styles.css';
import '@eevenkoto/css/license-bar.css';
import { renderLicenseBar } from '@eevenkoto/html';

renderLicenseBar({
  entries: [{ license: 'open', links: [{ label: 'SRD (CC-BY 4.0)', href: '/lisenssi' }] }],
  activeLicense: 'open',
  placement: 'inline',
});
```

```tsx
import '@eevenkoto/css/styles.css';
import '@eevenkoto/css/license-bar.css';
import { LicenseBar } from '@eevenkoto/react';

<LicenseBar
  entries={[{ license: 'open', links: [{ label: 'SRD (CC-BY 4.0)', href: '/lisenssi' }] }]}
  activeLicense="open"
  placement="inline"
/>
```
