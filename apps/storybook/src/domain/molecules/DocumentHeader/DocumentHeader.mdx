# DocumentHeader

Page-title row: heading, readiness Badge and an optional content-license toggle. Under `selectedLicense="open"` (or any `[data-content-license="open"]` ancestor) the H1 underline turns primary.

<Canvas of={DocumentHeaderStories.Default} />

<Controls of={DocumentHeaderStories.Default} />

## Why to use

Document pages repeat the same title row. Centralising it keeps readiness and license cues consistent and lets the license accent follow the active mode.

## When to use

- Use at the top of a document or chapter page.
- Pass the heading markup as the default slot / children (`heading` in `@eevenkoto/html`).
- Enable `showLicenseToggle` only where the reader may switch between proprietary and open text.

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `id` | `string` | — | Element `id` on `<header>`; prefixes the toggle input `name`. |
| `heading` | `string` / slot | — | Pre-rendered heading HTML in `@eevenkoto/html` (`children` / default slot in React, Vue, and Astro). |
| `showLicenseToggle` | `boolean` | `false` | Render the SegmentedControl edition toggle. |
| `selectedLicense` | `'proprietary' \| 'open'` | `'proprietary'` | Active license (`'open'` sets `eevenkoto-document-header--open`). |
| `licenseOptions` | `SegmentedControlOption[]` | — | Toggle options (links or radios for alternate editions). |
| `licenseLabel` | `string` | `'License'` | Toggle accessible label. |
| `readinessLabel` / `readinessIntent` | `string` / `BadgeIntent` | — / `'neutral'` | Optional readiness Badge. |

## Framework packages

`document-header.css` imports `badge.css`, `heading.css`, and `segmented-control.css` automatically (also import `icon.css` if `licenseOptions` include icons).

```ts
import '@eevenkoto/css/styles.css';
import '@eevenkoto/css/document-header.css';
import { renderDocumentHeader } from '@eevenkoto/html';

renderDocumentHeader({
  heading: '<h1 class="eevenkoto-heading">Velhon käsikirja</h1>',
  readinessLabel: 'Valmis',
  readinessIntent: 'success',
});
```

```tsx
import '@eevenkoto/css/styles.css';
import '@eevenkoto/css/document-header.css';
import { DocumentHeader } from '@eevenkoto/react';

<DocumentHeader readinessLabel="Valmis" readinessIntent="success">
  <h1 className="eevenkoto-heading">Velhon käsikirja</h1>
</DocumentHeader>
```
