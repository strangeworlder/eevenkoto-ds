# ReadAloudBox

Boxed text meant to be read aloud to players: thick accent inline-start rule, optional ornament, serif narration typography (cascading `--eevenkoto-font-serif` to nested `Paragraph` and `List` blocks), and `break-inside: avoid` so it never splits across printed pages.

<Canvas of={ReadAloudBoxStories.Default} />

```html
<aside class="eevenkoto-read-aloud-box">
  <span class="eevenkoto-read-aloud-box__ornament" aria-hidden="true">❖</span>
  <div class="eevenkoto-read-aloud-box__body eevenkoto-prose">
    <p>Sumu nousee kivisillalle, ja lyhdyt lepattavat tuulessa.</p>
  </div>
</aside>
```

<Controls of={ReadAloudBoxStories.Default} />

## Why to use

Read-aloud text is a recognisable adventure convention. A dedicated component keeps it semantically an aside and visually consistent.

## When to use

- Use for narration meant for players.
- Do not use for GM-only notes — use Notice.

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `id` | `string` | — | Host `<aside id>`. |
| `label` | `string` | — | Accessible `aria-label` for the `<aside>`. |
| `ornament` | `string \| false` | `'❖'` | Decorative glyph; `false` hides it. |
| `body` / `bodyHtml` | `string` | — | Plain-text or trusted inline/block HTML copy (or default slot/children). |

### Public CSS override tokens

| Token | Purpose |
| --- | --- |
| `--eevenkoto-read-aloud-box-bg` | Box surface (`surface-subtle`) |
| `--eevenkoto-read-aloud-box-text` | Read-aloud copy ink (`content-primary`) |
| `--eevenkoto-read-aloud-box-rule-color` | Inline-start accent rule (`content-accent-strong`) |
| `--eevenkoto-read-aloud-box-rule-width` | Inline-start accent rule width (`line-width-lg`) |
| `--eevenkoto-read-aloud-box-ornament-color` | Decorative ornament glyph color (`content-accent-strong`) |

## Framework packages

`read-aloud-box.css` imports `prose.css` automatically.

```ts
import '@eevenkoto/css/styles.css';
import '@eevenkoto/css/read-aloud-box.css';
import { renderReadAloudBox } from '@eevenkoto/html';

renderReadAloudBox({ body: 'Tunkkainen ilma…' });
```

```tsx
import '@eevenkoto/css/styles.css';
import '@eevenkoto/css/read-aloud-box.css';
import { ReadAloudBox } from '@eevenkoto/react';

<ReadAloudBox body="Tunkkainen ilma…" />
```
