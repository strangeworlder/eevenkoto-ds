# EntityPreview

TooltipCard specialised for referenced entities: optional kind badge, body, truncated note and footer link. A Statblock/Spellblock in the body renders flush.

<Canvas of={EntityPreviewStories.Default} />

```html
<div class="eevenkoto-tooltip-card eevenkoto-entity-preview" data-entity-kind="spell">
  <header>
    <h2>Tulipallo</h2>
  </header>
  <div class="eevenkoto-tooltip-card__body eevenkoto-prose" tabindex="0">
    <div class="eevenkoto-entity-preview__meta">
      <span class="eevenkoto-badge eevenkoto-badge--info"><span class="eevenkoto-badge__label">Loitsu</span></span>
    </div>
    <p>Räjähtävä pallo tulta.</p>
  </div>
  <footer>
    <a class="eevenkoto-link-button" href="/loitsut/tulipallo">Avaa sivu</a>
  </footer>
</div>
```

<Controls of={EntityPreviewStories.Default} />

## Why to use

Hover and popover previews for entity references all share structure and chrome; this keeps them consistent and avoids double borders around embedded blocks.

## When to use

- Use inside a Popover or tooltip target for EntityRef previews.
- Use TooltipCard for non-entity tooltips.

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `title` / `titleLevel` | `string` / `2 \| 3` | — / `2` | Header title and heading tag level. |
| `kind` | `EntityRefKind` | — | Sets `data-entity-kind` on the root card. |
| `badge` | `BadgeProps` | — | Optional kind / readiness Badge inside `.eevenkoto-entity-preview__meta`. |
| `body` / `bodyHtml` | `string` | — | Plain-text or trusted HTML body copy (`bodyHtml` wraps in `.eevenkoto-entity-preview__html`). |
| `content` | `string` / slot | — | Pre-rendered body HTML in `@eevenkoto/html` (`children` / default slot in React, Vue, and Astro). |
| `truncatedLabel` | `string` | — | Note shown when the preview was truncated. |
| `footerLink` | `LinkButtonProps` | — | Footer LinkButton to the full entry. |
| `flush` | `boolean` | `false` | Removes body padding for full-bleed embedded blocks. |

## Framework packages

`entity-preview.css` imports `tooltip-card.css` and `badge.css` automatically. Also import `@eevenkoto/css/link-button.css` when `footerLink` is passed (plus `icon.css` if `footerLink.icon` is set, and the stylesheets of any `Statblock` / `Spellblock` embedded in `body`).

```ts
import '@eevenkoto/css/styles.css';
import '@eevenkoto/css/entity-preview.css';
import '@eevenkoto/css/link-button.css';
import { renderEntityPreview } from '@eevenkoto/html';

renderEntityPreview({
  title: 'Tulipallo',
  kind: 'spell',
  badge: { label: 'Loitsu', intent: 'info' },
  body: 'Räjähtävä pallo tulta.',
  footerLink: { href: '/loitsut/tulipallo', label: 'Avaa sivu' },
});
```
