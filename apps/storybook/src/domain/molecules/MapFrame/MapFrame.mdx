# MapFrame

Figure wrapper for an inline SVG or image map with title, scale and caption.

<Canvas of={MapFrameStories.Default} />

<Controls of={MapFrameStories.Default} />

## Why to use

Maps need a consistent frame with title, scale and caption, and must not break across printed pages.

## When to use

- Use for adventure maps (inline SVG via `svgHtml` / children, or `src`).
- Provide `alt` for images and an accessible name for inline SVG.

<Canvas of={MapFrameStories.ImageSource} />

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `title` / `scale` | `string` | — | Header row title and scale label. |
| `svgHtml` | `string` | — | Trusted inline SVG markup (takes precedence over `src`). |
| `src` / `alt` | `string` | — | Image source URL and accessible text alternative. |
| `caption` / `captionHtml` | `string` | — | Plain or trusted inline HTML `<figcaption>`. |
| `id` | `string` | — | Host `<figure id>`. |

### Public CSS override tokens

| Token | Purpose |
| --- | --- |
| `--eevenkoto-map-frame-bg` | Outer frame background (`surface-raised`) |
| `--eevenkoto-map-frame-viewport-bg` | Map canvas well background (`surface-sunken`) |
| `--eevenkoto-map-frame-border-color` | Frame and band border (`boundary-subtle`) |
| `--eevenkoto-map-frame-text` | Title ink (`content-primary`) |
| `--eevenkoto-map-frame-muted` | Scale and caption ink (`content-secondary`) |

## Framework packages

```ts
import '@eevenkoto/css/styles.css';
import '@eevenkoto/css/map-frame.css';
import { renderMapFrame } from '@eevenkoto/html';

renderMapFrame({
  title: 'Kellari',
  src: '/map.png',
  alt: 'Kellarin kartta',
});
```

```tsx
import '@eevenkoto/css/styles.css';
```
