# ContentGate

Full-page gate shown when the reader's tier cannot open a document: neutral Calling Card passe-partout, readiness Badge + lock, heading, copy, current-vs-required tier comparison strip, actions, live status line and an optional dev footer.

```html
  <div class="eevenkoto-content-gate__status-row">

      <span class="eevenkoto-badge__label">Ennakko</span>
    </span>
    <span class="eevenkoto-content-gate__lock"><svg class="eevenkoto-icon" aria-hidden="true">…</svg></span>

  <h2 class="eevenkoto-heading eevenkoto-content-gate__title">Tämä luku on tukijoille</h2>
  <div class="eevenkoto-content-gate__description eevenkoto-prose">
    <p>Päivitä tilauksesi lukeaksesi luvun.</p>
  </div>
</section>
```

## Why to use

Gating a document needs a consistent, accessible explanation: what is locked, why, and what to do. A live status region announces async results without relying on colour.

## When to use

- Use when the reader cannot access a document and no public fallback exists.
- The status line is hidden until `statusMessage` is set.
- Put developer-only controls in the `footer` slot.

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `readinessLabel` / `readinessIntent` | `string` / `BadgeIntent` | **required** | Readiness Badge label and intent. |
| `lockLabel` | `string` | `'Locked'` | Accessible label for the lock Icon. |
| `title` / `titleLevel` | `string` / `1 \| 2 \| 3` | **required** / `2` | Gate heading text and tag level. |
| `description` / `descriptionHtml` | `string` | — | Plain-text or trusted HTML explanatory copy (or default slot/children). |
| `currentTierLabel` / `requiredTierLabel` | `string` | **required** | Comparison strip values. |
| `currentTierPrefix` / `requiredTierPrefix` | `string` | `'Current tier:'` / `'Required tier:'` | Localised comparison prefixes. |
| `statusMessage` | `string` | — | Live-region text; hidden when empty. |
| `actions` / `footer` | `string` / slot | — | Primary action buttons and optional dev-only footer. |
| `id` | `string` | — | Host `<section id>`. |

## Framework packages

`content-gate.css` imports `badge.css`, `icon.css`, `heading.css`, and `prose.css` automatically. Also import `link-button.css` / `button.css` for any CTAs placed inside `actions`.

```ts
import '@eevenkoto/css/styles.css';
import '@eevenkoto/css/content-gate.css';
import '@eevenkoto/css/link-button.css';
import { renderContentGate, renderLinkButton } from '@eevenkoto/html';

renderContentGate({
  readinessLabel: 'Ennakko',
  readinessIntent: 'caution',
  title: 'Lukittu',
  currentTierLabel: 'Seuraaja',
  requiredTierLabel: 'Kannattaja',
  actions: renderLinkButton({ href: '#join', label: 'Liity' }),
});
```
