# AbilityScoreGroup

**AbilityScoreGroup** is the Domain **organism** sandwich: optional header/footer rails + a responsive six→three column grid of [AbilityScore](?path=/docs/domain-molecules-abilityscore--docs) columns. It replaces the legacy `kykylistaus-*` table and sibling-paragraph CSS.

Rails typically hold [PropertyList](?path=/docs/core-molecules-propertylist--docs) vitals (header) and details (footer). See [Glossary](?path=/docs/foundations-glossary--docs).

## Why to use

Ability grids need a panel, noise surface, scoop corners, and a container query. AbilityScore owns one column; AbilityScoreGroup owns the sandwich layout.

## When to use

## Anatomy

1. **Root** — `.eevenkoto-ability-score-group` (`container-type: inline-size`)
2. **Header** — `.eevenkoto-ability-score-group__header` (optional inset scoop rail)
3. **Grid** — `.eevenkoto-ability-score-group__grid` (6 columns → 3)
4. **Footer** — `.eevenkoto-ability-score-group__footer` (optional inset scoop rail)

### Responsive behavior

| Container | Grid | Rails |
| --- | --- | --- |
| Wide | `repeat(6, 1fr)`, full width | Inset via `--eevenkoto-ability-score-group-inset-inline` |
| ≤ 650px | `repeat(3, 1fr)`, `max-width: 40rem`, centered | `width: 100%`, same `max-width` |

## Accessibility

- Group is a layout region; column AT lives on AbilityScore.
- Creature name / section headings live on Statblock, not here.

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `abilities` | `AbilityScoreProps[]` | — | Columns. |
| `header` | HTML string / `ReactNode` / Vue slot | — | Inset rail (typically PropertyList). |
| `footer` | HTML string / `ReactNode` / Vue slot | — | Inset rail (typically PropertyList). |

### CSS classes

| Class | Role |
| --- | --- |
| `eevenkoto-ability-score-group` | Group root |
| `eevenkoto-ability-score-group__header` / `__footer` / `__grid` | Sandwich regions |

### Public CSS override tokens

| Token | Purpose |
| --- | --- |
| `--eevenkoto-ability-score-group-inset-inline` | Header/footer side inset (wide) |
| `--eevenkoto-ability-score-group-bg` | Panel surface |
| `--eevenkoto-ability-score-group-border-color` | Panel border |
| `--eevenkoto-ability-score-group-radius` | Scoop radius |

Required CSS: `stat.css`, `ability-score.css` (+ `property.css` when using PropertyList rails). Public import path stays `@eevenkoto/css/ability-score.css`.

## Framework packages

```ts
import { renderAbilityScoreGroup, renderPropertyList } from '@eevenkoto/html';

renderAbilityScoreGroup({
  abilities: [/* … */],
  header: renderPropertyList({ items: vitals }),
  footer: renderPropertyList({ items: details }),
});
```

```tsx
import { AbilityScoreGroup, PropertyList } from '@eevenkoto/react';

<AbilityScoreGroup
  abilities={abilities}
  header={<PropertyList items={vitals} />}
  footer={<PropertyList items={details} />}
/>
```

```vue
<AbilityScoreGroup :abilities="abilities">
  <template #header><PropertyList :items="vitals" /></template>
  <template #footer><PropertyList :items="details" /></template>
</AbilityScoreGroup>
```
