# NpcCardGrid

Responsive grid of NpcCards: two columns on wide containers, one on narrow.

<Canvas of={NpcCardGridStories.Default} />

```html
<div class="eevenkoto-npc-card-grid">
  <article class="eevenkoto-npc-card">…</article>
  <article class="eevenkoto-npc-card">…</article>
</div>
```

<Controls of={NpcCardGridStories.Default} />

## Why to use

NPC lists should scan as a grid without every adventure re-implementing the layout.

## When to use

- Use for 2+ NPC entries.
- Use `columns={1}` for long entries.

<Canvas of={NpcCardGridStories.SingleColumn} />

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `cards` | `NpcCardProps[]` | — | Card data (or pass `NpcCard` children / default slot). |
| `columns` | `1 \| 2` | `2` | Maximum columns on wide containers. |
| `id` | `string` | — | Host element `id`. |

<ArgTypes of={NpcCardGridStories} />

### Public CSS override tokens

| Token | Purpose |
| --- | --- |
| `--eevenkoto-npc-card-grid-gap` | Grid gap (`space-4`) |
| `--eevenkoto-npc-card-grid-min` | Minimum card track width (`24rem`, `100%` when `columns={1}`) |

## Framework packages

`npc-card-grid.css` imports `npc-card.css` (and transitively `heading.css`, `property.css`, `prose.css`) automatically.

```ts
import '@eevenkoto/css/styles.css';
import '@eevenkoto/css/npc-card-grid.css';
import { renderNpcCardGrid } from '@eevenkoto/html';

renderNpcCardGrid({
  cards: [{ name: 'Aino Karhu', role: 'Kauppias' }],
});
```

```tsx
import '@eevenkoto/css/styles.css';
import '@eevenkoto/css/npc-card-grid.css';
import { NpcCardGrid } from '@eevenkoto/react';

<NpcCardGrid cards={[{ name: 'Aino Karhu', role: 'Kauppias' }]} />
```

```vue
<script setup>
import '@eevenkoto/css/styles.css';
import '@eevenkoto/css/npc-card-grid.css';
import { NpcCardGrid } from '@eevenkoto/vue';

const cards = [{ name: 'Aino Karhu', role: 'Kauppias' }];
</script>

<template>
  <NpcCardGrid :cards="cards" />
</template>
```
