# EquipmentWorkshop

**EquipmentWorkshop** ("Varusteverstas") is an interactive craft organism that allows players and game masters to design customized weapons, armor, and shields. It features a responsive two-column layout: interactive configuration controls on the left, and a sticky live preview rendered by `EquipmentBlock` on the right.

English code API (`EquipmentWorkshopProps`); Finnish game rules, default values, and presets live as data inside `@eevenkoto/core`.

<Canvas of={EquipmentWorkshopStories.Default} />

## Why to use

Interactive weapon and armor crafters in TTRPG websites frequently degrade into unmaintainable, ad-hoc "Frankenstein" components with raw hex colors, hardcoded CSS, and mismatched form elements. EquipmentWorkshop solves this by:

- **100% design system composition**: Reuses SegmentedControl, Input, Button, Badge, Chip, Notice, and EquipmentBlock.
- **Pure rule-engine separation**: Math, dice ladder calculations, trait budgets, and presets reside in `@eevenkoto/core` (`calculateWeapon`, `calculateArmor`).
- **Zero-runtime vanilla option**: SSR-friendly HTML markup with lightweight vanilla client-side interactivity (`initEquipmentWorkshop`), plus idiomatic React and Vue components.
- **Copy-to-clipboard**: Formats the final weapon or armor into standard Markdown suitable for Discord, roll20, or character sheet notes.

## Anatomy

```
EquipmentWorkshop
├── Header
│   ├── Segmented Control (Weapons vs Armor)
│   └── Preset Selector dropdown
├── Body (responsive 2-column grid)
│   ├── Controls Column
│   │   ├── Name row (input + randomizer button)
│   │   ├── Radio Grid (class, type)
│   │   ├── Trait selections (checkboxes, steppers)
│   │   └── Extra / Aether traits & Shield dropdown
│   └── Preview Column (sticky)
│       └── EquipmentBlock (live reactive update + copy button)
└── Toast feedback ("Varustetiedot kopioitu leikepöydälle!")
```

## Accessibility

- Mode switch uses standard `role="tablist"` or fieldset with radio inputs.
- Option groupings use accessible legends and labels.
- Stepper buttons provide clear `+` / `−` controls with accessible `disabled` states when budget limits are reached.
- Clipboard toast uses `role="alert"` and `aria-live="polite"`.

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `initialMode` | `'weapons' \| 'armor'` | `'weapons'` | Starting mode tab. |
| `initialWeapon` | `WeaponSpec` | `DEFAULT_WEAPON_SPEC` | Initial weapon specification. |
| `initialArmor` | `ArmorSpec` | `DEFAULT_ARMOR_SPEC` | Initial armor specification. |
| `idSuffix` | `string` | `''` | Suffix to ensure unique input IDs when multiple workshops exist. |

## Framework packages

```bash
npm install @eevenkoto/css @eevenkoto/html
# or @eevenkoto/react / @eevenkoto/vue
```

### Vanilla HTML / Astro

```astro
---
import '@eevenkoto/css/styles.css';
import '@eevenkoto/css/equipment-block.css';
import '@eevenkoto/css/equipment-workshop.css';
import { renderEquipmentWorkshop } from '@eevenkoto/html';
---

<div set:html={renderEquipmentWorkshop()} />

<script>
  import { autoInitEquipmentWorkshops } from '@eevenkoto/html';
  autoInitEquipmentWorkshops();
</script>
```

### React

```tsx
import '@eevenkoto/css/styles.css';
import '@eevenkoto/css/equipment-block.css';
import '@eevenkoto/css/equipment-workshop.css';
import { EquipmentWorkshop } from '@eevenkoto/react';

export default function WorkshopPage() {
  return <EquipmentWorkshop initialMode="weapons" />;
}
```

### Vue

```vue
<script setup>
import '@eevenkoto/css/styles.css';
import '@eevenkoto/css/equipment-block.css';
import '@eevenkoto/css/equipment-workshop.css';
import { EquipmentWorkshop } from '@eevenkoto/vue';
</script>

<template>
  <EquipmentWorkshop initial-mode="weapons" />
</template>
```
