# EquipmentWorkshop

**EquipmentWorkshop** (*Varusteverstas*) is the Domain **workbench chassis** for weapon, armor, and gear crafting UIs. It specializes Core [Workshop](?path=/docs/core-organisms-workshop--docs) (`eevenkoto-workshop` + `eevenkoto-equipment-workshop`) with equipment-specific control grouping helpers while pairing with [EquipmentBlock](?path=/docs/domain-organisms-equipmentblock--docs) in the sticky preview rail.

The design system owns the responsive 2-column layout, container-query stacking, and form/feedback chrome; the consumer app owns game rules, point-budget math, presets, and state.

## Why to use

Crafting tools need a responsive split workbench (controls on the inline-start rail, sticky `EquipmentBlock` preview on the inline-end rail, optional header/toolbar/footer) without hardcoding game math into `@eevenkoto/core` or inventing ad-hoc flex/grid wrappers per builder.

## When to use

Use `EquipmentWorkshop` for weapon, armor, and item builders paired with `EquipmentBlock`. For generic creature, encounter, or random-table generators that do not need the equipment control-group helpers, use Core [Workshop](?path=/docs/core-organisms-workshop--docs) directly.

## Architecture & ownership

> **Note:** Since `v0.9.3`, `@eevenkoto/core` does not ship hardcoded game math (`calculateWeapon`, `calculateArmor`). Reference rule-engine code and migration notes live in `docs/migration-equipment-workshop-chassis.md` and `apps/storybook/src/domain/organisms/EquipmentWorkshop/equipmentRules.ts`.

| Layer | Owner | Responsibility |
| --- | --- | --- |
| **Layout chassis** | Design System | `EquipmentWorkshop` (built on Core `Workshop`) owns the 2-column grid, `@container` collapse below `56rem`, sticky rail behavior, and control-group layout classes. |
| **Form & feedback chrome** | Design System | `Input`, `Select`, `Stepper`, `RadioGroup`, `CheckboxGroup`, `SegmentedControl`, `Button`, `Toast`. |
| **Presentation card** | Design System | `EquipmentBlock` renders computed stats, kesto breakdown, traits, warnings, and copy action. |
| **Rule engine & state** | Consumer app | Game formulas, point-budget validation, presets, and reactive form state. |

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `layout` | `'split' \| 'inline'` | `'split'` | Workbench geometry (`'split'` 2-column or `'inline'` single-column). |
| `sticky` | `'preview' \| 'controls' \| 'none'` | `'preview'` (`'none'` in `inline`) | Sticky column behavior above `56rem` container width. |
| `header` | `ReactNode \| string` | — | Top header bar (title, mode switcher, preset picker). |
| `controls` | `ReactNode \| string` | — | Inline-start form controls column (or children / default slot). |
| `toolbar` | `ReactNode \| string` | — | Optional sunken summary/export bar above `preview`. |
| `preview` | `ReactNode \| string` | — | Inline-end live preview rail (typically `EquipmentBlock`). |
| `footer` | `ReactNode \| string` | — | Optional top-bordered footer tray below the body. |
| `id` | `string` | — | Explicit host element `id` (React, Vue, and Astro HTML attributes). |
| `idSuffix` | `string` | — | Appends `equipment-workshop{idSuffix}` as the host `id`. |

### CSS classes

`EquipmentWorkshop` composes Core [Workshop](?path=/docs/core-organisms-workshop--docs) (`eevenkoto-workshop` + `eevenkoto-equipment-workshop`) and supports both BEM prefixes:

| Class | Role |
| --- | --- |
| `eevenkoto-workshop` / `eevenkoto-equipment-workshop` | Root workbench container |
| `eevenkoto-workshop__header` / `eevenkoto-equipment-workshop__header` | Top header bar |
| `eevenkoto-workshop__body` / `eevenkoto-equipment-workshop__body` | Responsive 2-column grid |
| `eevenkoto-workshop__controls` / `eevenkoto-equipment-workshop__controls` | Form controls column |
| `eevenkoto-workshop__toolbar` / `eevenkoto-equipment-workshop__toolbar` | Sunken toolbar inside preview |
| `eevenkoto-workshop__preview` / `eevenkoto-equipment-workshop__preview` | Sticky preview column |
| `eevenkoto-workshop__footer` / `eevenkoto-equipment-workshop__footer` | Bottom tray |
| `eevenkoto-equipment-workshop__control-group` | Vertical control group stack |
| `eevenkoto-equipment-workshop__group-label` | Group heading label |
| `eevenkoto-equipment-workshop__group-hint` | Group helper text |
| `eevenkoto-equipment-workshop__name-row` | Item name + randomize button row |
| `eevenkoto-equipment-workshop__stepper-grid` | Stepper stack/grid |

## Framework packages

`equipment-workshop.css` imports `workshop.css` (and `icon.css`) automatically. Also import the stylesheets of the form controls and `EquipmentBlock` companion sheets placed inside `controls` and `preview`.

```ts
import '@eevenkoto/css/styles.css';
import '@eevenkoto/css/heading.css';
import '@eevenkoto/css/caption.css';
import '@eevenkoto/css/badge.css';
import '@eevenkoto/css/chip.css';
import '@eevenkoto/css/equipment-block.css';
import '@eevenkoto/css/equipment-workshop.css';
import { renderEquipmentWorkshop, renderEquipmentBlock } from '@eevenkoto/html';

renderEquipmentWorkshop({
  header: '<strong>Aseverstas</strong>',
  controls: '<div class="eevenkoto-equipment-workshop__control-group">…</div>',
  preview: renderEquipmentBlock({ name: 'Korppiterä', price: '25 kr', traits: ['Viiltävä'] }),
});
```
