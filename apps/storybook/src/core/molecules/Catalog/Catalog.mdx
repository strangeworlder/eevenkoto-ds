# Catalog

A **dense index grid** of linked tiles. Each [CatalogTile](#api-reference) is a raised hairline row (optional StatusDot + name + lock). The Catalog host is `repeat(auto-fill, minmax(12.5rem, 1fr))` — not a general layout kit.

<Canvas of={CatalogStories.Default} />

```html
<ul class="eevenkoto-catalog">
  <li>
    <a class="eevenkoto-catalog-tile" href="/spells/aavevalo">Aavevalo</a>
  </li>
</ul>
```

### Playground

<Controls of={CatalogStories.Default} />

## Why to use

Spell, creature, and culture indexes need compact linked rows in a wrapping grid. Card is too tall; List is a vertical stack; Menu is navigation chrome. Catalog is that index so eevenko.to can drop `.entity-grid` / `.entity-item`.

## API reference

### Catalog

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `tiles` | `CatalogTileProps[]` | — | Grid items. |
| `label` | `string` | — | Accessible name for the list. |

### CatalogTile

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `name` | `string` | — | Visible label. |
| `href` | `string` | — | Destination (required). |
| `status` | `BadgeIntent` | — | Leading StatusDot. |
| `statusLabel` | `string` | `'Ready'` | AT name for the pip. |
| `locked` | `boolean` | `false` | Trailing lock. |
| `lockedLabel` | `string` | `'Locked'` | AT name for the lock. |

### Public CSS override tokens

| Token | Purpose |
| --- | --- |
| `--eevenkoto-catalog-tile-bg` | Tile fill (`surface-raised`, `surface-subtle` on hover/focus) |

| `--eevenkoto-catalog-tile-lock-color` | Trailing lock icon color (`content-accent-strong`) |

## Framework packages

`catalog.css` imports `status-dot.css` and `icon.css` automatically. Both `Catalog` (`renderCatalog`) and standalone `CatalogTile` (`renderCatalogTile`) are exported.

```ts
import '@eevenkoto/css/styles.css';
import '@eevenkoto/css/catalog.css';
import { renderCatalog, renderCatalogTile } from '@eevenkoto/html';

renderCatalog({
  label: 'Loitsut',
  tiles: [{ name: 'Aavevalo', href: '/spells/aavevalo', status: 'success', statusLabel: 'Valmis' }],
});

renderCatalogTile({ name: 'Tulipallo', href: '/spells/tulipallo', locked: true });
```

```tsx
import '@eevenkoto/css/styles.css';
import '@eevenkoto/css/catalog.css';
import { Catalog, CatalogTile } from '@eevenkoto/react';

<>
  <Catalog
    label="Loitsut"
    tiles={[{ name: 'Aavevalo', href: '/spells/aavevalo', status: 'success', statusLabel: 'Valmis' }]}
  />

</>
```
