# Notice

A **Notice** is a feedback callout or banner. It consumes Tier 2 **`feedback`** intents (same set as Badge) with optional icon, title, body, and actions slots.

<Canvas of={NoticeStories.Default} />

Host alone is **subtle** + **neutral**. `resolveNoticeRole` defaults `caution` and `critical` intents to `role="alert"` and other intents to `role="status"` (override with `role="status" | "alert" | "note" | "region"`). Each intent also renders a matching leading `Icon` by default (`icon={false}` to omit).

## Notice vs Card

| Need | Use |
| --- | --- |
| Status, validation, gate, or system message (intent-colored) | **Notice** |
| Sectioned content tile (header / body / footer), item teaser | **[Card](?path=/docs/core-molecules-card--docs)** |
| Elevate or make a content summary clickable | Card `--elevated` / `--interactive` |
| Feedback chrome inside a larger layout | Notice (optionally **inside** a Card — do not restyle Card as a Notice) |

Agents: if the copy is about what went wrong, what’s locked, or what succeeded, start with **Notice**. If it’s a self-contained content chunk (item, teaser), start with **Card**.

## Why to use

Readers need a scannable block that signals status — locked section, success, caution — with the same intent language as Badge, but as a banner rather than a chip. Notice owns that feedback surface so products do not paint Card or Paragraph in feedback colors.

## When to use

## Live status feedback

Pass `statusText` when an action inside the notice produces inline confirmation copy (rendered as `<p class="eevenkoto-notice__status" role="status" aria-live="polite">`).

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `intent` | `'neutral' \| 'info' \| 'success' \| 'caution' \| 'critical' \| 'admin'` | `'neutral'` | Feedback color intent (`eevenkoto-notice--{intent}`). |
| `variant` | `'subtle' \| 'outline' \| 'solid'` | `'subtle'` | Surface loudness (`eevenkoto-notice--{variant}`). |
| `title` | `string` | — | Bold heading line in `__title` (`line-height-snug`). |
| `body` | `string` | — | Plain-text body copy in `__body` (optional when using slots or `bodyHtml`). |
| `bodyHtml` | `string` | — | Trusted pre-rendered HTML for `__body` (takes precedence over `body`). |
| `icon` | `IconName \| false` | intent default (`info`, `check`, `warning`, `star`) | Leading decorative Icon, or `false` to omit. |
| `role` | `'status' \| 'alert' \| 'note' \| 'region'` | `'alert'` for `caution`/`critical`, `'status'` otherwise | ARIA landmark/live-region role. |
| `statusText` | `string` | — | Polite live-region confirmation line (`__status`). |
| `actions` | `string` / slot | — | Action controls rendered inside `__actions`. |
| `id` | `string` | — | Host element `id` (React, Vue, and Astro HTML attributes). |

### Public CSS override tokens

| Token | Purpose |
| --- | --- |
| `--eevenkoto-notice-bg` | Callout surface (`feedback-*-background` in subtle) |
| `--eevenkoto-notice-text` | Title and body ink |
| `--eevenkoto-notice-border-color` | Callout border color |
| `--eevenkoto-notice-border-width` | Callout border width (`line-width-sm`) |
| `--eevenkoto-notice-icon` | Leading icon ink |
| `--eevenkoto-notice-radius` | Corner radius (`radius-sm`) |
| `--eevenkoto-notice-padding` | Inner padding (`space-4`) |
| `--eevenkoto-notice-gap` | Grid gap between icon and content (`space-3`) |
| `--eevenkoto-notice-title-weight` | Title font weight (`font-weight-bold`) |
| `--eevenkoto-notice-font-size` | Body font size (`font-size-body-md`) |
| `--eevenkoto-notice-link-color` | Inline bare `<a href>` ink (defaults to `currentColor` for feedback contrast safety) |
| `--eevenkoto-notice-link-underline` | Inline bare `<a href>` underline color (`currentColor`) |

## Framework packages

Import `@eevenkoto/css/notice.css` and `@eevenkoto/css/icon.css` (Notice renders an intent Icon by default unless `icon: false`).

```ts
import '@eevenkoto/css/styles.css';
import '@eevenkoto/css/notice.css';
import '@eevenkoto/css/icon.css';
import { renderNotice } from '@eevenkoto/html';

renderNotice({
  intent: 'caution',
  title: 'Ennakkoversio',
  body: 'Säännöt saattavat päivittyä ennen julkaisua.',
});
```

```tsx
import '@eevenkoto/css/styles.css';
import '@eevenkoto/css/notice.css';

import { Notice } from '@eevenkoto/react';
```
