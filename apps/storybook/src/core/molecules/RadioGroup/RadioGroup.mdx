# RadioGroup

Semantic fieldset grouping mutually exclusive radio options with an accessible `<legend>`. Supports uniform styling via `variant="card"` or `variant="tile"`, vertical stack or grid layouts, and error messaging.

<Canvas of={RadioGroupStories.Default} />

Host alone renders a vertical list of radio options.

### Playground

<Controls of={RadioGroupStories.Default} />

## Why to use

Groups of mutually exclusive choices need an accessible group name for screen readers, keyboard arrow navigation between options, and layout options for cards with rich descriptions or compact grid tiles.

## When to use

<DoDont
  do={
    <ul>
      <li>Use RadioGroup when the user must select exactly one option from 2 to 7 visible choices.</li>
      <li>Use <code>variant="card"</code> when options have descriptive subtitles or mechanics text.</li>
      <li>Use <code>variant="tile"</code> with <code>layout="grid"</code> for compact multi-column selectors.</li>
    </ul>
  }
  dont={
    <ul>
      <li>Don't use RadioGroup when multiple selections are allowed — use <strong>CheckboxGroup</strong>.</li>
      <li>Don't use RadioGroup for long lists (8+ items) in cramped dialogs — use <strong>Select</strong>.</li>
    </ul>
  }
/>

## RadioGroup vs other single-select controls

| Need | Recommended Component | Option Count | Layout & Scanning |
| --- | --- | --- | --- |
| **Form data choice (high visibility, scannable)** | **RadioGroup** | 2–5 | All options exposed simultaneously. Arrow keys navigate. Can show mechanics descriptions. |
| **Long list of choices (space constrained)** | **Select** | 6–50+ | Single-row collapsed height. Opens OS native picker. Supports `<optgroup>`. |
| **In-page view switcher / mode toggle** | **SegmentedControl** | 2–4 | Connected horizontal pills. For layout/document mode changes, not form questionnaires. |
| **Multi-select (0 to N items)** | **CheckboxGroup** | Any | Checkboxes with independent states. Optional budget counter badge. |

### Variant chooser: Default vs Card vs Tile

- **`variant="default"`**: Plain inline radio buttons for standard vertical form questions (e.g. "Difficulty: Easy / Normal / Hard").
- **`variant="card"`**: Rich cards with border and background tint, with room for subtitle `description` and price badges (e.g. Weapon type choice in Varusteverstas).
- **`variant="tile"` + `layout="grid"`**: Symmetric compact tiles arranged in 2 or 3 columns (e.g. Armor categories "Kevyt", "Keskiraskas", "Raskas", or die chains "1n6", "1n8", "1n10").

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `name` | `string` | **required** | Shared name attribute for child radios. |
| `label` | `string` | **required** | Group legend label. |
| `value` | `string` | — | Currently selected value. |
| `defaultValue` | `string` | — | Initial selected value if uncontrolled. |
| `layout` | `'stack' \| 'grid'` | `'stack'` | Arrangement of items. |
| `columns` | `2 \| 3` | `2` | Column count when `layout="grid"`. |
| `variant` | `'default' \| 'card' \| 'tile'` | `'default'` | Shared option variant. |
| `hint` | `string` | — | Explanatory helper text. |
| `error` | `string` | — | Validation error text. |
| `options` | `RadioGroupOptionProps[]` | — | Declarative list of radio options. |

```tsx
// React
import { RadioGroup } from '@eevenkoto/react';

<RadioGroup
  name="weaponType"
  label="Asetyyppi"
  value={weaponType}

  variant="card"
  options={[

/>
```
