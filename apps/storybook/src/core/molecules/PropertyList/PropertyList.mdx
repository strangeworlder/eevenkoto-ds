# PropertyList

**PropertyList** is the Core **molecule** that arranges **Property** rows in a semantic definition list (`dl`). Property itself is the row atom (`dt` / `dd` inside a grouping `div`).

HTML5 allows a grouping `div` inside `dl` so each pair can be one flex row or grid tile (`.eevenkoto-property`) without adjacent-sibling hacks. In `inline` and `divided` layouts, the colon after the term is rendered by CSS (`dt::after`), not stored in the label string; `grid` and `cards` suppress the colon and render tracked uppercase labels above semibold values.

<Canvas of={PropertyListStories.Default} />

```html
<dl class="eevenkoto-property-list">
  <div class="eevenkoto-property">
    <dt class="eevenkoto-property__label">Defense</dt>
    <dd class="eevenkoto-property__value">15</dd>
  </div>
  <div class="eevenkoto-property">
    <dt class="eevenkoto-property__label">Initiative</dt>
    <dd class="eevenkoto-property__value">+1 (11)</dd>
  </div>
</dl>
```

## Why to use

Combat vitals, casting bands, equipment stats, skills, senses, and summary tiles are definitional metadata. A real `dl` exposes that relationship to assistive tech across stacked rows, hairline-divided lists, multi-column bands, and bordered stat cards — without bold Paragraph + `<br>` scaffolding.

## Layouts

### Divided (`layout="divided"`)

Inline `Label: Value` rows separated by `--eevenkoto-color-boundary-subtle` hairlines.

<Canvas of={PropertyListStories.Divided} />

### Grid (`layout="grid"`)

Multi-column band (defaults to `columns={4}`, collapsing to 2 columns below `40rem` and 1 column below `26rem`) with tracked uppercase serif labels (`content-accent-strong`) and semibold values.

<Canvas of={PropertyListStories.Grid} />

### Cards with secondary `meta` (`layout="cards"`)

Bordered `surface-subtle` tiles (defaults to `columns={2}`) with optional `meta` line(s) stacked inside `<dd class="eevenkoto-property__value">`.

<Canvas of={PropertyListStories.CardsWithMeta} />

## Anatomy

1. **PropertyList** — `dl.eevenkoto-property-list`
2. **Property** — grouping `div.eevenkoto-property`
3. **Label** — `dt.eevenkoto-property__label` (`::after` colon in `inline` / `divided`, suppressed in `grid` / `cards`)
4. **Value** — `dd.eevenkoto-property__value`
5. **Meta (optional)** — `span.eevenkoto-property__meta` stacked below the primary value inside `dd`

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `items` (list) | `PropertyItem[]` | — | Rows to render. |
| `layout` (list) | `'inline' \| 'divided' \| 'grid' \| 'cards'` | `'inline'` | Visual arrangement of definition pairs. |
| `columns` (list) | `2 \| 3 \| 4` | `4` (`grid`) / `2` (`cards`) | Column count for `grid` and `cards` layouts. |
| `label` (item) | `string` | — | Term (no colon). |
| `value` (item) | `string` | — | Primary detail text. |
| `valueHtml` (item) | `string` | — | Trusted pre-rendered inline HTML for `dd`. |
| `meta` (item) | `string \| string[]` | — | Optional secondary metadata line(s) stacked below `value`. |

### CSS classes

| Class | Role |
| --- | --- |
| `eevenkoto-property-list` | `dl` root (host alone = `inline`) |
| `eevenkoto-property-list--divided` | Hairline-separated inline rows |
| `eevenkoto-property-list--grid` | Multi-column stacked metadata band |
| `eevenkoto-property-list--cards` | Multi-column bordered card tiles |
| `eevenkoto-property-list--cols-2` / `--cols-3` / `--cols-4` | Explicit grid/card column count |
| `eevenkoto-property` | Row / tile group |
| `eevenkoto-property__label` | `dt` |
| `eevenkoto-property__value` | `dd` |
| `eevenkoto-property__meta` | Secondary metadata line inside `dd` |

### Public CSS override tokens

| Token | Purpose |
| --- | --- |
| `--eevenkoto-property-list-gap` | Gap between rows / grid cells |
| `--eevenkoto-property-list-margin-block` | List block margins |
| `--eevenkoto-property-list-cols` | Grid / cards column count |
| `--eevenkoto-property-list-divider-color` | Divider hairline in `--divided` |
| `--eevenkoto-property-label-color` / `-value-color` / `-meta-color` | Ink overrides |
| `--eevenkoto-property-card-bg` / `-card-border-color` | Tile fill & border in `--cards` |
| `--eevenkoto-property-font-size` | Type size (defaults to `body-md`) |
| `--eevenkoto-property-gap` | Label↔value gap |
| `--eevenkoto-property-label-weight` | Term weight (defaults to bold) |

Required CSS: `property.css`.

## Framework packages

```ts
import '@eevenkoto/css/property.css';
import { renderPropertyList } from '@eevenkoto/html';

renderPropertyList({
  layout: 'grid',
  items: [
    { label: 'Puolustus', value: '15' },
    { label: 'Aloite', value: '+1 (11)' },
  ],
});
```

```tsx
import { PropertyList } from '@eevenkoto/react';

<PropertyList
  layout="cards"
  items={[
    { label: 'Pitkämiekka', value: '1n8 viilto', meta: 'Paino 1,5 kg' },
    { label: 'Kilpi', value: '+2 Puolustus', meta: 'Paino 3 kg' },
  ]}
/>
```

```vue
<script setup>
import { PropertyList } from '@eevenkoto/vue';

const items = [
  { label: 'Puolustus', value: '15' },
  { label: 'Aloite', value: '+1 (11)' },
];
</script>

<template>
  <PropertyList layout="divided" :items="items" />
</template>
```
