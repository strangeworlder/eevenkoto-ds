# Table

Core **molecule** for real `<table>` charts. Composes [TableCell](?path=/docs/core-atoms-tablecell--docs) atoms. For framed/scrollable product charts, wrap with [TableShell](?path=/docs/core-organisms-tableshell--docs).

<Canvas of={TableStories.Default} />

Minimum markup is the host class: `<table class="eevenkoto-table">` is the **default** variant with **row** striping. Cells need `eevenkoto-table-cell` (kind defaults to text without `--text`). Opt out of stripes with `eevenkoto-table--stripe-none`.

### Playground

<Controls of={TableStories.Default} />

## Variants

| Variant | Use |
| --- | --- |
| `default` | Everyday multi-column grids |
| `numeric` | Progression charts — angled numeric headers, upright index/text |
| `pair` | Roll / index → description (rulebook look) |

### Numeric progression

Long headers over single-digit cells: only **numeric** heads rotate (−45°). Full text stays in the DOM. Hover/focus a numeric head to outline that column. `prefers-reduced-motion: reduce` keeps headers upright and wrapping.

<Canvas of={TableStories.NumericProgression} />

### Pair / roll

Use a real table for lookup charts. Prefer [PropertyList](?path=/docs/core-molecules-propertylist--docs) for definitional label→value metadata (“Armor Class: 15”).

<Canvas of={TableStories.PairRoll} />

### Stripe

Default `row` zebra uses `surface-subtle` on the host (no `--stripe-row` required). `column` stripes digit columns; `none` (`eevenkoto-table--stripe-none`) turns striping off. Borders remain so color is not the only structure cue.

<Canvas of={TableStories.StripeColumn} />

## Ecosystem

```
TableCell + Caption  →  Table (molecule)  →  TableShell (Frame + Scroll + footer slot)
```

Pager is not shipped yet — put future Pager in the TableShell footer slot.

## Framework packages

```ts
import '@eevenkoto/css/table-cell.css';
import '@eevenkoto/css/table.css';
import { renderTable } from '@eevenkoto/html';

renderTable({
  variant: 'pair',
  caption: 'Class progression',
  columns: [
    { key: 'class', header: 'Class', kind: 'index' },
    { key: 'hit', header: 'Hit die', kind: 'text' },
  ],
  rows: [
    ['Fighter', 'd10'],
    ['Wizard', 'd6'],
  ],
});
```

```tsx
import '@eevenkoto/css/table-cell.css';
import '@eevenkoto/css/table.css';
import { Table } from '@eevenkoto/react';

<Table
  variant="pair"
  caption="Class progression"
  columns={[
    { key: 'class', header: 'Class', kind: 'index' },
    { key: 'hit', header: 'Hit die', kind: 'text' },
  ]}
  rows={[
    ['Fighter', 'd10'],
    ['Wizard', 'd6'],
  ]}
/>
```

```vue
<script setup>
import '@eevenkoto/css/table-cell.css';
import '@eevenkoto/css/table.css';
import { Table } from '@eevenkoto/vue';

const columns = [
  { key: 'class', header: 'Class', kind: 'index' },
  { key: 'hit', header: 'Hit die', kind: 'text' },
];
const rows = [
  ['Fighter', 'd10'],
  ['Wizard', 'd6'],
];
</script>

<template>
  <Table variant="pair" caption="Class progression" :columns="columns" :rows="rows" />
</template>
```
