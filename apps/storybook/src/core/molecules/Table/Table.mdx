# Table

Core **molecule** for real `<table>` charts. Composes [TableCell](?path=/docs/core-atoms-tablecell--docs) atoms. For framed/scrollable product charts, wrap with [TableShell](?path=/docs/core-organisms-tableshell--docs).

<Canvas of={TableStories.Default} />

Minimum markup is the host class: `<table class="eevenkoto-table">` is the **default** variant with **row** striping. Everything that can only live inside a table — `caption`, `col`, `tr`, `th`, `td` — is styled from the host, so those tags stay bare. Cells get the [TableCell](?path=/docs/core-atoms-tablecell--docs) recipe with `text` as the default kind; add `eevenkoto-table-cell--index` / `--numeric` (and the matching `eevenkoto-table__col--*`) only for narrow columns. Opt out of stripes with `eevenkoto-table--stripe-none`.

```html
<table class="eevenkoto-table">
  <caption>Class progression</caption>
  <colgroup>
    <col class="eevenkoto-table__col--index" />
    <col />
  </colgroup>
  <thead>
    <tr>
      <th scope="col" class="eevenkoto-table-cell--index">Level</th>
      <th scope="col">Feature</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td class="eevenkoto-table-cell--index">1</td>
      <td>Spellcasting</td>
    </tr>
  </tbody>
</table>
```

## Why to use

Rulebooks and tools rely on real `<table>` charts (class progression, roll lookups, equipment catalogs) with tabular numerals, angled numeric headers, and row/column striping that work in screen readers and print without ad-hoc table CSS.

## When to use

Use Table for true multi-column tabular data or roll/index lookup charts. Wrap wide tables in [TableShell](?path=/docs/core-organisms-tableshell--docs) (or Domain [ContentTable](?path=/docs/domain-molecules-contenttable--docs) when rows carry readiness states or spanning locked-tier Notices), and use [PropertyList](?path=/docs/core-molecules-propertylist--docs) for single-entity label→value pairs.

## Variants

| Variant | Use |
| --- | --- |
| `default` | Everyday multi-column grids |
| `numeric` | Progression charts — angled numeric headers, upright index/text |
| `pair` | Roll / index → description (rulebook look) |

### Numeric progression

Long headers over single-digit cells: only **numeric** heads rotate (−45°). Full text stays in the DOM. Hover/focus a numeric head to outline that column. `prefers-reduced-motion: reduce` keeps headers upright and wrapping.

<Canvas of={TableStories.NumericProgression} />

### Pair / roll

Use a real table for lookup charts. Prefer [PropertyList](?path=/docs/core-molecules-propertylist--docs) for definitional label→value metadata (“Armor Class: 15”).

<Canvas of={TableStories.PairRoll} />

### Stripe

Default `row` zebra uses `surface-subtle` on the host (no `--stripe-row` required). `column` stripes digit columns; `none` (`eevenkoto-table--stripe-none`) turns striping off. Borders remain so color is not the only structure cue.

<Canvas of={TableStories.StripeColumn} />

### Rich HTML, spanned cells & row attributes

`rows` accepts plain `string[][]` for compact tables as well as structured `TableRowObject` (`{ attributes, cells }`) and `TableCellObject` (`{ text, html, kind, colSpan, rowSpan, header, scope, attributes }`) for inline [EntityRef](?path=/docs/domain-atoms-entityref--docs) links, category group subheaders (`header: true, scope: 'colgroup', colSpan`), and filterable `data-*` attributes.

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `columns` | `TableColumn[]` | **required** | Header columns (`{ key, header, kind? }`). |
| `rows` | `TableRowInput[]` | **required** | Row cells (`string[][]`, `TableCellObject[]`, or `TableRowObject` with `attributes` + `cells`). |
| `caption` | `string` | — | Optional `<caption>` copy. |
| `variant` | `'default' \| 'numeric' \| 'pair'` | `'default'` | Table layout recipe (`eevenkoto-table--numeric` / `--pair`). |
| `stripe` | `'row' \| 'column' \| 'none'` | `'row'` | Alternating surface band (`eevenkoto-table--stripe-column` / `--stripe-none`). |
| `id` | `string` | — | Host `<table id>` (React, Vue, and Astro HTML attributes). |

### Public CSS override tokens

| Token | Purpose |
| --- | --- |
| `--eevenkoto-table-bg` | Table surface (`surface-canvas`) |
| `--eevenkoto-table-header-bg` | `<thead>` row background (`surface-sunken`) |
| `--eevenkoto-table-header-color` | `<thead>` header ink (`content-accent`) |
| `--eevenkoto-table-header-border-color` | `<thead>` bottom rule color (`boundary-strong`) |
| `--eevenkoto-table-header-border-width` | `<thead>` bottom rule thickness (`line-width-md`) |
| `--eevenkoto-table-stripe-bg` | Alternating row stripe fill (`surface-subtle`) |
| `--eevenkoto-table-col-highlight` | Alternating column stripe fill (`--stripe-column`) |
| `--eevenkoto-table-caption-color` | `<caption>` ink (`content-secondary`) |
| `--eevenkoto-table-caption-font-size` | `<caption>` font size (`font-size-caption`) |

## Framework packages

`table.css` imports `table-cell.css` automatically.

```ts
import '@eevenkoto/css/styles.css';
import '@eevenkoto/css/table.css';
import { renderTable } from '@eevenkoto/html';

renderTable({
  variant: 'pair',
  caption: 'Class progression',
  columns: [
    { key: 'class', header: 'Class', kind: 'index' },
    { key: 'hit', header: 'Hit die', kind: 'text' },
  ],
  rows: [
    ['Fighter', 'd10'],
    ['Wizard', 'd6'],
  ],
});
```
