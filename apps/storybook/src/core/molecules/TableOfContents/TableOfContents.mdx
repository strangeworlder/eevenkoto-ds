# TableOfContents

A `<nav>` outline of in-page jump links. It replaces horizontal chip bars with a real list: a vertical **rail** on wide layouts and a sticky **disclosure** on narrow ones. The current location is shown with `aria-current="location"` plus a thick accent border and heavier weight, so it never relies on color alone.

<Canvas of={TableOfContentsStories.Rail} />

```html
<nav class="eevenkoto-toc" aria-label="Table of contents">
  <div class="eevenkoto-toc__rail">
    <p class="eevenkoto-toc__heading">On this page</p>
    <div class="eevenkoto-toc__group">
      <ul class="eevenkoto-toc__list">
        <li><a class="eevenkoto-toc__link" href="#overview" aria-current="location">Overview</a></li>
        <li><a class="eevenkoto-toc__link" href="#details">Details</a></li>
      </ul>
    </div>
  </div>
</nav>
```

<Controls of={TableOfContentsStories.Rail} />

## Why to use

Long documents need a navigable outline that works without JavaScript, stays reachable on mobile, and is skipped in print. Links use `data-toc-target` (never duplicate ids), so one scrollspy updates both presentations.

## When to use

- Use `variant="auto"` for document pages with a side column.
- Use `rail` inside a layout you already control, `collapsible` for single-column pages.
- Don't use it for site navigation — use [Menu](?path=/docs/core-molecules-menu--docs).

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `id` | `string` | — | DOM id on `<nav>`. |
| `label` | `string` | `'Table of contents'` | Landmark `aria-label`. |
| `groups` | `TableOfContentsGroup[]` | — | `{ id?, label?, items: { id, href, label, current? }[] }`. |
| `variant` | `'auto' \| 'rail' \| 'collapsible'` | `'auto'` | Presentation. |
| `toggleLabel` | `string` | `'On this page'` | Rail heading and disclosure summary. |
| `open` | `boolean` | `false` | Start the disclosure open. |

### Public CSS override tokens

| Token | Purpose |
| --- | --- |
| `--eevenkoto-toc-muted` | Toggle summary muted ink (`content-secondary`) |
| `--eevenkoto-toc-eyebrow` | Group heading eyebrow ink (`content-accent-strong`) |
| `--eevenkoto-toc-text` | Active item ink (`content-primary`) |
| `--eevenkoto-toc-surface` | Collapsible panel surface (`surface-raised`) |
| `--eevenkoto-toc-border-color` | Rail/panel border (`boundary-subtle`) |
| `--eevenkoto-toc-link-color` | Resting item link ink |
| `--eevenkoto-toc-link-bg` | Item row background (`transparent` at rest) |
| `--eevenkoto-toc-link-border-color` | Active indicator rail border |
| `--eevenkoto-toc-link-weight` | Item font weight |

## Framework packages

`table-of-contents.css` imports `icon.css` automatically.

```ts
import '@eevenkoto/css/styles.css';
import '@eevenkoto/css/table-of-contents.css';
import { renderTableOfContents } from '@eevenkoto/html';

renderTableOfContents({ groups: [{ items: [{ id: 'a', href: '#a', label: 'A' }] }] });
```

```tsx
import '@eevenkoto/css/styles.css';
import '@eevenkoto/css/table-of-contents.css';
import { TableOfContents } from '@eevenkoto/react';

<TableOfContents
  groups={[{ items: [{ id: 'a', href: '#a', label: 'Overview', current: true }] }]}
  variant="auto"
/>
```

```vue
<script setup>
import '@eevenkoto/css/styles.css';
import '@eevenkoto/css/table-of-contents.css';
import { TableOfContents } from '@eevenkoto/vue';

const groups = [{ items: [{ id: 'a', href: '#a', label: 'Overview', current: true }] }];
</script>

<template>
  <TableOfContents :groups="groups" variant="auto" />
</template>
```
