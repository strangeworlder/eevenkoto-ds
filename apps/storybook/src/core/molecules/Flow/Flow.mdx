# Flow

Flow is the vertical rhythm container for stacked primitives. It resets child block margins and applies pair-aware gaps so Heading, Paragraph, and Caption never invent competing space.

<Canvas of={FlowStories.Default} />

```html
<div class="eevenkoto-flow">
  <h2 class="eevenkoto-heading …">…</h2>
  <p class="eevenkoto-paragraph …">…</p>
</div>
```

## Why to use

Type primitives need default margins for standalone stories, but those margins **stack** in compositions — especially with global `text-box` trim removing half-leading. Flow owns the gaps instead.

## When to use

Wrap any vertical stack of Heading / Paragraph / Caption (and nested Flows) in `eevenkoto-flow`. For bare CMS/`h*`/`p` markup, compose with [Prose](?path=/docs/core-molecules-prose--docs) (`eevenkoto-prose eevenkoto-flow`).

## Density

| Modifier | Class | Effect |
| --- | --- | --- |
| _(default)_ | `eevenkoto-flow` | Comfortable reading rhythm |
| `tight` | `eevenkoto-flow--tight` | Compact stacks |
| `loose` | `eevenkoto-flow--loose` | Airier editorial layouts |

## Pair rules (defaults)

Gaps use `padding-block-start` on the following sibling (not stacked margins), so rhythm survives margin collapse and global `text-box` trim.

| Adjacent pair | Gap token fallback |
| --- | --- |
| Generic sibling | `--eevenkoto-space-4` |
| Heading → Paragraph / Caption | `--eevenkoto-space-4` |
| Paragraph / Caption → Heading | `--eevenkoto-space-8` |
| → H1 / H2 | `--eevenkoto-space-8` |
| Paragraph → Paragraph | `--eevenkoto-space-4` |
| → Caption | `--eevenkoto-space-2` |
| Nested Flow → Flow | `--eevenkoto-space-8` |
| Run-in H6 → Paragraph | `0` (inline) |

## Framework packages

HTML takes a `content` string. React/Vue use children / the default slot instead.

```ts
import '@eevenkoto/css/flow.css';
import { renderFlow, renderHeading, renderParagraph } from '@eevenkoto/html';

renderFlow({
  content: [
    renderHeading({ level: 2, text: 'Title' }),
    renderParagraph({ text: 'Body.' }),
  ].join(''),
});
```

```tsx
import { Flow, Heading, Paragraph } from '@eevenkoto/react';

<Flow>
  <Heading level={2} text="Title" />
  <Paragraph text="Body." />
</Flow>
```

```vue
<script setup>
import { Flow, Heading, Paragraph } from '@eevenkoto/vue';
</script>

<template>
  <Flow>
    <Heading :level="2" text="Title" />
    <Paragraph text="Body." />
  </Flow>
</template>
```
