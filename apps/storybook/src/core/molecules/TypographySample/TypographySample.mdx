# Typography sample

A reading-flow specimen that composes [Flow](?path=/docs/core-molecules-flow--docs), [Heading](?path=/docs/core-atoms-heading--docs), [Paragraph](?path=/docs/core-atoms-paragraph--docs), [List](?path=/docs/core-molecules-list--docs), [Caption](?path=/docs/core-atoms-caption--docs), and Core form controls ([Input](?path=/docs/core-atoms-input--docs), [Checkbox](?path=/docs/core-atoms-checkbox--docs), [Radio](?path=/docs/core-atoms-radio--docs)) — not a token swatch grid.

Vertical gaps are owned by **Flow** (pair-aware rhythm), not by stacking each primitive’s default margins.

Use it to judge hierarchy, rhythm, and color together: macro rules, meso weight, micro bands and run-ins, as well as embedded form controls in document flow.
