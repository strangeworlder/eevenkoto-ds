# ChipGroup

A `<fieldset>` with a `<legend>` and a wrapping list of [Chip](?path=/docs/core-atoms-chip--docs)s. Each chip carries `data-value` so host scripts can wire selection; `mode` is exposed as `data-selection-mode`.

<Canvas of={ChipGroupStories.SingleSelect} />

```html
<fieldset class="eevenkoto-chip-group" data-selection-mode="single">
  <legend class="eevenkoto-chip-group__legend">Piiri</legend>
  <div class="eevenkoto-chip-group__list">
    <button type="button" class="eevenkoto-chip eevenkoto-chip--sm eevenkoto-chip--selected" data-value="0" aria-pressed="true">Taikakonsti</button>
    <button type="button" class="eevenkoto-chip eevenkoto-chip--sm" data-value="1" aria-pressed="false">1. piiri</button>
  </div>
</fieldset>
```

<Controls of={ChipGroupStories.SingleSelect} />

## Why to use

One accessible structure (group name, per-chip `aria-pressed`) for filters and color pickers, with leading `icon` and `swatchColor` support and disabled chips that keep their contrast.

## When to use

- Use for compact, visible filter or picker options.
- Use `hideLegend` when the heading is already on screen (the legend stays for screen readers).
- Don't use for exclusive form choices that need native radios — use [RadioGroup](?path=/docs/core-molecules-radiogroup--docs).

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `id` | `string` | — | DOM id on `<fieldset>`. |
| `label` | `string` | — | Legend text. |
| `hideLegend` | `boolean` | `false` | Visually hide the legend. |
| `mode` | `'single' \| 'multiple'` | `'single'` | Selection semantics (`data-selection-mode`). |
| `size` | `ChipSize` | `'sm'` | Chip size. |
| `hidden` | `boolean` | `false` | Hide the whole group. |
| `options` | `ChipGroupOption[]` | — | `{ value, label, selected?, disabled?, title?, icon?, swatchColor?, href?, attributes? }`. |

## Framework packages

`chip-group.css` imports `chip.css` (and transitively `icon.css` + `swatch.css`) automatically.

```ts
import '@eevenkoto/css/styles.css';
import '@eevenkoto/css/chip-group.css';
import { renderChipGroup } from '@eevenkoto/html';

renderChipGroup({ label: 'Level', options: [{ value: '1', label: 'Level 1', selected: true }] });
```

```tsx
import { useState } from 'react';
import '@eevenkoto/css/styles.css';
import '@eevenkoto/css/chip-group.css';
import { ChipGroup } from '@eevenkoto/react';

export function LevelFilter() {
  const [selected, setSelected] = useState('1');
  return (
    <ChipGroup
      label="Level"
      options={[
        { value: '1', label: 'Level 1', selected: selected === '1' },
        { value: '2', label: 'Level 2', selected: selected === '2' },
      ]}
      onSelect={setSelected}
    />
  );
}
```

```vue
<script setup>
import { ref } from 'vue';
import '@eevenkoto/css/styles.css';
import '@eevenkoto/css/chip-group.css';
import { ChipGroup } from '@eevenkoto/vue';

const selected = ref('1');
</script>

<template>
  <ChipGroup
    label="Level"
    :options="[
      { value: '1', label: 'Level 1', selected: selected === '1' },
      { value: '2', label: 'Level 2', selected: selected === '2' },
    ]"
    @select="(v) => (selected = v)"
  />
</template>
```
