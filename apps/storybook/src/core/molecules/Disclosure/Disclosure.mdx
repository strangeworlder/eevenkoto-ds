# Disclosure

A native `<details>`/`<summary>` expander. The summary carries a label, optional secondary text, optional leading and trailing slots, and a chevron that rotates when open. The body is wrapped in `.eevenkoto-prose`.

<Controls of={DisclosureStories.Default} />

## Why to use

Keyboard- and screen-reader-accessible expand/collapse with no JavaScript, tokenized surfaces and focus ring, and forced-colors and print support.

## When to use

- Use for optional detail, FAQs, and grouped filters.
- Use `variant="flush"` inside cards or lists, `emphasized` for a focal item.
- Don't use it for primary navigation — use [Menu](?path=/docs/core-molecules-menu--docs).

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `id` | `string` | — | DOM id on `<details>`. |
| `label` | `string` | — | Summary label. |
| `summaryText` | `string` | — | Muted secondary summary text. |
| `variant` | `'card' \| 'subtle' \| 'flush'` | `'card'` | Surface treatment. |
| `open` | `boolean` | `false` | Start expanded. |
| `emphasized` | `boolean` | `false` | Accent border. |
| `body` / `bodyHtml` | `string` | — | Plain or trusted HTML (slot/children wins). |
| `summaryLead` / `summaryMeta` | slot / prop | — | Leading and trailing summary content. |
