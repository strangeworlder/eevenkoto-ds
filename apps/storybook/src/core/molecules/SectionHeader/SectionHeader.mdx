# SectionHeader

A standard header lockup for editorial sections and hero blocks: an accent **eyebrow**, optional **logo**, a semantic **heading**, a **lead** paragraph, an **actions** row and a reassurance **note**. Child margins and the heading underline are neutralized so spacing comes from the lockup's gap.

## Why to use

Pages repeat the same kicker/title/lead/CTA arrangement. SectionHeader keeps heading levels explicit (`titleLevel`) and spacing consistent while composing Caption, Heading and Paragraph.

## When to use

- Use at the top of a page section or as a centered hero.
- Choose `titleLevel` from document structure, not from desired size.
- Don't use it for card titles — use [Card](?path=/docs/core-molecules-card--docs).

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `eyebrow` | `string` | — | Uppercase accent kicker. |
| `title` / `titleHtml` | `string` | — | Heading text or trusted inline HTML. |
| `titleLevel` | `1 \| 2 \| 3` | `2` | Semantic heading level. |
| `logo` | `{ src, alt, width?, height? }` | — | Brand image. |
| `lead` / `leadHtml` | `string` | — | Lead paragraph. |
| `align` | `'start' \| 'center'` | `'start'` | Alignment. |
| `note` | `{ icon?, text?, html? }` | — | Reassurance line. |
| `actions` | slot / prop | — | Buttons or links row. |
