# SectionHeader

A standard header lockup for editorial sections and hero blocks: an accent **eyebrow**, optional **logo**, a semantic **heading**, a **lead** paragraph, an **actions** row and a reassurance **note**. Child margins and the heading underline are neutralized so spacing comes from the lockup's gap.

<Canvas of={SectionHeaderStories.EditorialStart} />

```html
<header class="eevenkoto-section-header">
  <p class="eevenkoto-caption eevenkoto-caption--accent eevenkoto-caption--eyebrow">Luku I</p>
  <h2 class="eevenkoto-heading">Maailman luominen</h2>
  <p class="eevenkoto-paragraph eevenkoto-paragraph--lg eevenkoto-paragraph--secondary eevenkoto-section-header__lead">
    Perusrakenteet kampanjan aloittamiseen.
  </p>
</header>
```

## Why to use

Pages repeat the same kicker/title/lead/CTA arrangement. SectionHeader keeps heading levels explicit (`titleLevel`) and spacing consistent while composing Caption, Heading and Paragraph.

## When to use

- Use at the top of a page section or as a centered hero.
- Choose `titleLevel` from document structure, not from desired size.
- Don't use it for card titles — use [Card](?path=/docs/core-molecules-card--docs).

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `eyebrow` | `string` | — | Uppercase accent kicker. |
| `title` / `titleHtml` | `string` | — | Heading text or trusted inline HTML. |
| `titleLevel` | `1 \| 2 \| 3` | `2` | Semantic heading level. |
| `logo` | `{ src, alt, width?, height? }` | — | Brand image. |
| `lead` / `leadHtml` | `string` | — | Lead paragraph. |
| `align` | `'start' \| 'center'` | `'start'` | Alignment. |
| `note` | `{ icon?, text?, html? }` | — | Reassurance line. |
| `actions` | slot / prop | — | Buttons or links row. |
| `id` | `string` | — | Host element `id`. |

## Framework packages

`section-header.css` imports `caption.css`, `heading.css`, `paragraph.css`, and `icon.css` automatically. Import `link-button.css` / `button.css` when passing action controls.

```ts
import '@eevenkoto/css/styles.css';
import '@eevenkoto/css/section-header.css';
import { renderSectionHeader } from '@eevenkoto/html';

renderSectionHeader({ eyebrow: 'Guide', title: 'Getting started', lead: 'Begin here.' });
```

```tsx
import '@eevenkoto/css/styles.css';
import '@eevenkoto/css/section-header.css';
import '@eevenkoto/css/link-button.css';
import { SectionHeader, LinkButton } from '@eevenkoto/react';

<SectionHeader title="Getting started" actions={<LinkButton href="#start" label="Start" />} />
```

```vue
<script setup>
import '@eevenkoto/css/styles.css';
import '@eevenkoto/css/section-header.css';
import '@eevenkoto/css/link-button.css';
import { SectionHeader, LinkButton } from '@eevenkoto/vue';
</script>

<template>
  <SectionHeader title="Getting started">

      <LinkButton href="#start" label="Start" />
    </template>

```
