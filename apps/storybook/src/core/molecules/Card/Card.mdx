# Card

Self-contained **1920s Letterpress Calling Card** surface. The host is an `<article>` wrapping optional `<header>`, flow (`<p>`, …), and `<footer>`, framed by a guillotine-cut `0px` outer border, a `4px` paper margin, and a concave-scooped inner passe-partout hairline (`::before`). The host class alone styles those tags — no region BEM is required for the default look. Host alone is a flat raised calling card with compartment dividers and no interaction affordance.

<Canvas of={CardStories.Default} />

```html
<article class="eevenkoto-card">
  <header>
    <h2>Cloak of Elvenkind</h2>
  </header>
  <p>
    While you wear this cloak with its hood up, Wisdom (Perception) checks made to see you have
    disadvantage.
  </p>
  <footer>Wondrous item, uncommon</footer>
</article>
```

The title is a real heading (default **H2**). Card remaps the look on the header (`Outfit` bold at `heading-4` scale with `0.015em` tracking) — do not compose the Heading atom. `__header` / `__body` / `__footer` remain optional aliases.

## Card vs Frame / Notice

| Need | Use |
| --- | --- |
| Thin portable bordered box (charts, tables, token panels) | **[Frame](?path=/docs/core-atoms-frame--docs)** |
| Sectioned content with header / body / footer rhythm | **Card** |
| Elevation or clickable summary tile | Card `--elevated` / `--interactive` |
| Dense entity index (name + pip) | **[Catalog](?path=/docs/core-molecules-catalog--docs)** |
| Status / gate / warning banner (intent-colored) | **[Notice](?path=/docs/core-molecules-notice--docs)** — not Card |

## Why to use

Item entries, paywall summaries, and other self-contained chunks need a surface with optional title and footer chrome — not a full page layout and not a bare Frame. Card owns that sectioned calling card so products do not invent one-off bordered panels for every teaser. Copy-paste HTML is a document (`article` + heading), not a div sandwich.

## Surfaces & featured frame

`surface` switches the background fill between `raised` (default), `subtle`, and `sunken`. `featured` (`.eevenkoto-card--featured`) upgrades the passe-partout to a gilded brass frame (`2px` outer rule + `1px` inner hairline and compartment dividers).

## Current state & header actions

Set `current` (`.eevenkoto-card--current`) to mark an active plan or selected card with a club-turquoise passe-partout (`2px` outer rule + `1px` turquoise inner hairline; when combined with `featured`, turquoise outer trim pairs with a gilded brass inner passe-partout), reserving the outer dual-halo focus ring for `:focus-visible`. Use `headerActions` (`.eevenkoto-card__header-actions`) for trailing badges or compact buttons inside `<header>`, and `titleHtml` when the heading contains inline emphasis or cross-references.

## Split banner layout

`layout="split"` (`.eevenkoto-card--split`) places the main content stack on the inline-start side and `.eevenkoto-card__actions` on the inline-end side, wrapping cleanly on narrow viewports and sidebars.

## Interactive

The host stays `<article>`. `renderCard({ href })` wraps the sections in an inner link and adds `--interactive`. Hover warms the cardstock fill, illuminates the passe-partout in club turquoise, and lifts the card with a crisp cardstock shadow.

```html
<article class="eevenkoto-card eevenkoto-card--interactive">
  <a href="#item">
    <header>
      <h2>Open the item entry</h2>
    </header>
    <p>Interactive cards gain hover, focus, and disabled affordances.</p>
  </a>
</article>
```

## Anatomy

| Part | Role |
| --- | --- |
| Host | `<article class="eevenkoto-card">` (outer trim border + `4px` paper margin) |
| Passe-partout | `::before` pseudo-element inset by the paper margin (concave-scooped corners where supported) |
| Header | descendant `header` (optional `.eevenkoto-card__header`) with hairline joining the passe-partout |
| Title | `h2` (or `h3` via `titleLevel`) inside `header`, from `title` or `titleHtml` |
| Header actions | `.eevenkoto-card__header-actions` pushed to `inline-end` inside `header` |
| Body | flow siblings (`p`, …) — `.eevenkoto-card__body` groups main content in `split` layout |
| Actions | `.eevenkoto-card__actions` for CTA buttons (inline-end in `split` layout) |
| Footer | descendant `footer` (optional `.eevenkoto-card__footer`) with hairline joining the passe-partout |
| Interactive | inner `a[href]` wrapping the sections; `--interactive` on the article |

## Framework packages

Hand-authored HTML is the reference. `renderCard` emits the same tags from `title` / `body` / `footer`.

```ts
import '@eevenkoto/css/styles.css';
import '@eevenkoto/css/card.css';
import { renderCard } from '@eevenkoto/html';

renderCard({
  title: 'Cloak of Elvenkind',
  body: 'While you wear this cloak with its hood up, Wisdom (Perception) checks made to see you have disadvantage.',
  footer: 'Wondrous item, uncommon',
});
```

```tsx
import '@eevenkoto/css/styles.css';
import '@eevenkoto/css/card.css';
import { Card } from '@eevenkoto/react';

<Card title="Cloak of Elvenkind" footer="Wondrous item, uncommon">
  While you wear this cloak with its hood up, Wisdom (Perception) checks made to see you have
  disadvantage.
</Card>
```

```vue
<script setup>
import '@eevenkoto/css/styles.css';
import '@eevenkoto/css/card.css';
import { Card } from '@eevenkoto/vue';
</script>

<template>
  <Card title="Cloak of Elvenkind">
    While you wear this cloak with its hood up, Wisdom (Perception) checks made to see you have
    disadvantage.
    <template #footer>Wondrous item, uncommon</template>
  </Card>
</template>
```

```astro
---
import '@eevenkoto/css/styles.css';
import '@eevenkoto/css/card.css';
import { Card } from '@eevenkoto/astro';
---

<Card title="Cloak of Elvenkind">
  <p>
    While you wear this cloak with its hood up, Wisdom (Perception) checks made to see you have
    disadvantage.
  </p>
  <span slot="footer">Wondrous item, uncommon</span>
</Card>
```

Pair `--interactive` with a real inner link so keyboard activation works; `aria-disabled="true"` on the article or the inner `a` carries the disabled recipe.

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `surface` | `'raised' \| 'subtle' \| 'sunken'` | `'raised'` | Surface fill tier (`eevenkoto-card--surface-*`). |
| `featured` | `boolean` | `false` | Highlights the card with a gilded brass passe-partout frame (`eevenkoto-card--featured`). |
| `current` | `boolean` | `false` | Active/selected card with a club-turquoise passe-partout frame (`eevenkoto-card--current`). |
| `layout` | `'stack' \| 'split'` | `'stack'` | Content/actions arrangement (`eevenkoto-card--split`). |
| `elevated` | `boolean` | `false` | Adds crisp cardstock shadow (`eevenkoto-card--elevated`). |
| `interactive` | `boolean` | `false` | Hover/focus affordance for inner link/button (`eevenkoto-card--interactive`). |
| `title` | `string` | — | Heading text inside `<header>`. |
| `titleHtml` | `string` | — | Trusted pre-rendered inline HTML for `<header>` heading (takes precedence over `title`). |
| `titleLevel` | `2 \| 3` | `2` | Heading level (`h2` or `h3`) for `title` / `titleHtml`. |
| `header` | `string` / slot | — | Custom `<header>` content (`header` prop in HTML/React; `#header` / `slot="header"` in Vue/Astro). |
| `headerActions` | `string` / slot | — | Trailing chrome inside `<header>` (`.eevenkoto-card__header-actions`). |
| `body` | `string` | — | Body copy rendered as `<p>` when slots/`bodyHtml` are omitted. |
| `bodyHtml` | `string` | — | Trusted pre-rendered HTML for card body copy (takes precedence over `body`). |
| `content` | `string` / slot | — | Main card body (`content` in `@eevenkoto/html`; `children` / default slot in React, Vue, and Astro). |
| `actions` | `string` / slot | — | Action group slot (`.eevenkoto-card__actions`), inline-end in `split` layout. |
| `footer` | `string` / slot | — | Footer content inside `<footer>`. |
| `href` | `string` | — | Wraps inner content in `<a href>` and enables `--interactive` across HTML, React, Vue, and Astro. |
| `id` | `string` | — | Host `<article id>` (React, Vue, and Astro HTML attributes). |

### Public CSS override tokens

| Token | Purpose |
| --- | --- |
| `--eevenkoto-card-bg` | Card surface fill (`surface-raised` by default) |
| `--eevenkoto-card-text` | Body text color (`content-primary`) |
| `--eevenkoto-card-muted` | Muted footer ink (`content-secondary`) |
| `--eevenkoto-card-border-color` | Outer trim border (`boundary-strong`; `content-accent-strong` on `--featured`; `feedback-info-icon` on `--current`) |
| `--eevenkoto-card-border-width` | Outer trim border width (`line-width-sm`; `line-width-md` on `--featured` / `--current`) |
| `--eevenkoto-card-inner-border-color` | Inner passe-partout hairline (`boundary-subtle`; `content-accent` on `--featured`; `feedback-info-border` on `--current`) |
| `--eevenkoto-card-inner-border-width` | Inner passe-partout hairline width (`line-width-sm`) |
| `--eevenkoto-card-frame-gap` | Paper margin between outer trim and inner passe-partout (`space-1`) |
| `--eevenkoto-card-radius` | Outer cardstock corner radius (`0`) |
| `--eevenkoto-card-inner-radius` | Inner passe-partout corner scoop radius (`radius-sm`) |
| `--eevenkoto-card-pad-block` / `--eevenkoto-card-pad-inline` | Section padding (`space-3` / `space-4`) |
| `--eevenkoto-card-gap` | Gap between card sections (`space-2`) |
| `--eevenkoto-card-shadow` | Crisp cardstock shadow (`none` unless `--elevated` or `--interactive` hover) |
| `--eevenkoto-card-divider-color` / `--eevenkoto-card-divider-width` | Header and footer compartment rule (`boundary-subtle` / `line-width-sm`; `content-accent` on `--featured`; `feedback-info-border` on `--current`) |
| `--eevenkoto-card-title-weight` / `--eevenkoto-card-title-tracking` | Header title weight (`font-weight-bold`) and tracking (`0.015em`) |
