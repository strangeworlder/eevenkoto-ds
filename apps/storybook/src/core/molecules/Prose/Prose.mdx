# Prose

Prose is the scope host for **bare** `h1`–`h6`, `p`, `ul`, `ol`, and `li`. Those tags receive the same default look as `eevenkoto-heading` / `eevenkoto-paragraph` / `eevenkoto-list`. Prose does **not** own vertical rhythm — compose with [Flow](?path=/docs/core-molecules-flow--docs).

<Canvas of={ProseStories.Default} />

```html
<div class="eevenkoto-prose">
  <h1>Title</h1>
  <p>Body copy without BEM classes.</p>
  <ul>
    <li>Bare list item</li>
  </ul>
</div>
```

<Controls of={ProseStories.Default} />

## Why to use

CMS HTML, markdown, and editorial content often ship tags without DS classes. Prose opts those tags into the type system without restyling every `h1`/`p`/`ul` in the document.

## When to use

<DoDont
  do={
    <ul>
      <li>Wrap reading/CMS content in <code>eevenkoto-prose</code>.</li>
      <li>Compose <code>eevenkoto-prose eevenkoto-flow</code> when you need pair-aware gaps.</li>
      <li>Prefer classed Heading/Paragraph/List outside Prose when you control the markup.</li>
    </ul>
  }
  dont={
    <ul>
      <li>Don’t expect bare tags to style outside Prose.</li>
      <li>Don’t use Prose as a substitute for Flow on classed primitive stacks.</li>
      <li>Don’t style global <code>h1</code>/<code>p</code>/<code>ul</code> in app CSS — keep the opt-in scope.</li>
    </ul>
  }
/>

## With Flow

Bare-tag pair rules activate only when **both** hosts are present.

<Canvas of={ProseStories.WithFlow} />

```html
<div class="eevenkoto-prose eevenkoto-flow">
  <h2>Section</h2>
  <p>Rhythm matches classed Heading → Paragraph pairs.</p>
  <ul>
    <li>Lists participate in the same stack.</li>
  </ul>
</div>
```

## Level override

Tag inference yields to an explicit `--N` modifier on a classed heading (same cascade as minimum-class Heading).

<Canvas of={ProseStories.LevelOverride} />

```html
<div class="eevenkoto-prose eevenkoto-flow">
  <h1 class="eevenkoto-heading eevenkoto-heading--3">Looks like H3</h1>
  <p>…</p>
</div>
```

## Imports

Type appearance lives in `heading.css`, `paragraph.css`, and `list.css`. Always import them with Prose:

```ts
import '@eevenkoto/css/prose.css';
import '@eevenkoto/css/heading.css';
import '@eevenkoto/css/paragraph.css';
import '@eevenkoto/css/list.css';
import '@eevenkoto/css/flow.css'; // when composing rhythm
```

## Framework packages

HTML takes a `content` string. React/Vue use children / the default slot.

```ts
import '@eevenkoto/css/prose.css';
import '@eevenkoto/css/heading.css';
import '@eevenkoto/css/paragraph.css';
import '@eevenkoto/css/list.css';
import { renderProse } from '@eevenkoto/html';

renderProse({
  content: '<h1>Title</h1><p>Body.</p><ul><li>Item</li></ul>',
});
```

```tsx
import { Prose } from '@eevenkoto/react';

<Prose className="eevenkoto-flow">
  <h1>Title</h1>
  <p>Body.</p>
  <ul>
    <li>Item</li>
  </ul>
</Prose>
```

```vue
<script setup>
import { Prose } from '@eevenkoto/vue';
</script>

<template>
  <Prose class="eevenkoto-flow">
    <h1>Title</h1>
    <p>Body.</p>
    <ul>
      <li>Item</li>
    </ul>
  </Prose>
</template>
```
