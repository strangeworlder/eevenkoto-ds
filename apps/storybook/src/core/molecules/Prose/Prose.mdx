# Prose

Prose is the scope host for **bare** `h1`–`h6`, `p`, `ul`, `ol`, `li`, `hr`, `blockquote`, `dl` (`dt`/`dd`), `img`, and unclassed `a` links. Those tags receive the same default look as `eevenkoto-heading` / `eevenkoto-paragraph` / `eevenkoto-list` / `eevenkoto-divider` and Tier 2 `link-*` tokens, while `:where(:not([class^="eevenkoto-"], [class*=" eevenkoto-"]))` prevents Prose rules from bleeding into nested DS components. Prose trims leading/trailing block margins on its first and last direct children and gives boxed DS blocks (`Notice`, `Card`, `Table`, `Statblock`, `Spellblock`, `EquipmentBlock`, `Workshop`, etc.) `space-6` block breathing room when used standalone; compose with [Flow](?path=/docs/core-molecules-flow--docs) for full pair-aware vertical rhythm. Printing the outermost Prose host columnizes long articles; nested Prose sections do not ([Print columns](?path=/docs/foundations-print-columns--docs)).

## Why to use

CMS HTML, markdown, and editorial content often ship tags without DS classes. Prose opts those tags into the type system without restyling every `h1`/`p`/`ul` in the document.

## When to use

Use Prose around rendered Markdown, CMS HTML, or long-form editorial sections where elements arrive without BEM classes; add `eevenkoto-flow` alongside `eevenkoto-prose` when you want pair-aware vertical rhythm.

## With Flow

Bare-tag pair rules activate only when **both** hosts are present.

<Canvas of={ProseStories.WithFlow} />

```html
  <h2>Section</h2>
  <p>Rhythm matches classed Heading → Paragraph pairs.</p>
  <ul>
    <li>Lists participate in the same stack.</li>
  </ul>

```

## Level override

Tag inference yields to an explicit `--N` modifier on a classed heading (same cascade as minimum-class Heading).

<Canvas of={ProseStories.LevelOverride} />

```html
<div class="eevenkoto-prose eevenkoto-flow">
  <h1 class="eevenkoto-heading eevenkoto-heading--3">Looks like H3</h1>
  <p>…</p>
</div>
```

## Imports

`prose.css` pulls in `heading.css`, `paragraph.css`, `list.css`, and `divider.css`, so bare tags under Prose match classed Heading / Paragraph / **List** (`.eevenkoto-list`) / **Divider** (`<hr>`). Add Flow when you need pair-aware rhythm:

```ts
import '@eevenkoto/css/prose.css';
import '@eevenkoto/css/flow.css'; // when composing rhythm
```

Import `list.css` on its own when you use classed `<ul class="eevenkoto-list">` outside Prose.

## Framework packages

`prose.css` imports `heading.css`, `paragraph.css`, `list.css`, and `divider.css` automatically. Compose with `@eevenkoto/css/flow.css` (`class="eevenkoto-flow"`) for vertical rhythm. HTML takes a `content` string; React, Vue, and Astro use children / the default slot.

```ts
import '@eevenkoto/css/styles.css';
import '@eevenkoto/css/prose.css';
import '@eevenkoto/css/flow.css';
import { renderProse } from '@eevenkoto/html';

renderProse({
  content: '<h1>Title</h1><p>Body.</p><ul><li>Item</li></ul>',
});
```

```tsx
import '@eevenkoto/css/styles.css';
import '@eevenkoto/css/prose.css';
import '@eevenkoto/css/flow.css';
import { Prose } from '@eevenkoto/react';

<Prose className="eevenkoto-flow">
  <h1>Title</h1>
  <p>Body.</p>
  <ul>
    <li>Item</li>
  </ul>
</Prose>
```
