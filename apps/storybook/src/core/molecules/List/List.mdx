# List

**List** is the Core **molecule** that stacks **ListItem** rows in a semantic content list (`ul` / `ol`). ListItem is the row atom (`li`). Use [PropertyList](?path=/docs/core-molecules-propertylist--docs) for definitional label→value metadata (`dl`).

The host class alone is the default (unordered / `body-md` / primary). Item look comes from `:where(ul, ol).eevenkoto-list > :where(li)` — bare direct-child `<li>` elements need no item class, and loose Markdown `<p>` wrappers inside `<li>` collapse single-item margins automatically. Ordered lists use `ol` (or `--ordered`); size and tone modifiers are opt-in. Framework helpers still emit explicit `--unordered` / `--md` / `--primary` for the component API.

```html
<ul class="eevenkoto-list">
  <li>Inspect the valve before engaging the primary circuit.</li>
  <li>Record pressure readings at each checkpoint.</li>
</ul>
```

## Why to use

Reading content often needs bulleted or numbered steps. Real `ul` / `ol` / `li` keep semantics honest for assistive tech and let Prose style bare CMS tags the same way as classed Lists.

## When to use

Use List for unordered or ordered content lists in reading layouts. Prefer PropertyList for vitals and other definitional metadata. Prefer Paragraph for multi-sentence prose without markers.

## Anatomy

1. **List** — `ul.eevenkoto-list` or `ol.eevenkoto-list` (host type, markers, and item look)
2. **ListItem** — bare `li` under the host (framework prop `text`; no required item class)

## Key modifiers

### variant

| Value | Element | Marker |
| --- | --- | --- |
| `unordered` | `ul` | `disc` (default) |
| `ordered` | `ol` | `decimal` |
| `checklist` | `ul` | Status `Icon` (`included` → `check`, `accent` → `star`, `excluded` → `close` + strikethrough + SR `"Excluded: "` prefix) |

Tag inference: `:where(ol).eevenkoto-list` and bare `ol` under Prose are ordered without requiring `--ordered`.

## API reference

<ArgTypes of={ListStories} />

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `items` | `ListItemProps[]` | — | Rows to render. |
| `variant` | `'unordered' \| 'ordered' \| 'checklist'` | `unordered` | List kind / element. |
| `size` | `'sm' \| 'md' \| 'lg'` | `md` | Body type size. |
| `tone` | `'primary' \| 'secondary'` | `primary` | Content color. |
| `text` (item) | `string` | — | Item copy. |
| `html` (item) | `string` | — | Trusted pre-rendered inline HTML (takes precedence over `text`). |
| `status` (item) | `'included' \| 'accent' \| 'excluded'` | `'included'` (in checklist) | Checklist row status icon and treatment. |

```ts
export type ListItemStatus = 'included' | 'accent' | 'excluded';

export interface ListItemProps {
  text?: string;
  html?: string;
  status?: ListItemStatus;
}

export interface ListProps {
  items: ListItemProps[];
  variant?: 'unordered' | 'ordered' | 'checklist';
  size?: 'sm' | 'md' | 'lg';
  tone?: 'primary' | 'secondary';
}
```

## Framework packages

`list.css` imports `icon.css` automatically and styles both `List` (`renderList`) and `ListItem` (`renderListItem`).

```ts
import '@eevenkoto/css/styles.css';
import '@eevenkoto/css/list.css';
import { renderList, renderListItem } from '@eevenkoto/html';

renderList({
  variant: 'unordered',
  items: [{ text: 'First step.' }, { text: 'Second step.' }],
});

`<ul class="eevenkoto-list eevenkoto-list--checklist">${renderListItem({
  text: 'Early access',
  status: 'included',
})}</ul>`;
```
