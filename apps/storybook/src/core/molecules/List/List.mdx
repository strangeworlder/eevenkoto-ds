# List

**List** is the Core **molecule** that stacks **ListItem** rows in a semantic content list (`ul` / `ol`). ListItem is the row atom (`li`). Use [PropertyList](?path=/docs/core-molecules-propertylist--docs) for definitional label→value metadata (`dl`).

The host class alone is the default (unordered / `body-md` / primary). Item look comes from `ul.eevenkoto-list li` / `ol.eevenkoto-list li` — bare `<li>` children need no item class. Ordered lists use `ol` (or `--ordered`); size and tone modifiers are opt-in. Framework helpers still emit explicit `--unordered` / `--md` / `--primary` for the component API.

<Canvas of={ListStories.Default} />

```html
<ul class="eevenkoto-list">
  <li>Inspect the valve before engaging the primary circuit.</li>
  <li>Record pressure readings at each checkpoint.</li>
</ul>
```

## Why to use

Reading content often needs bulleted or numbered steps. Real `ul` / `ol` / `li` keep semantics honest for assistive tech and let Prose style bare CMS tags the same way as classed Lists.

## When to use

Use List for unordered or ordered content lists in reading layouts. Prefer PropertyList for vitals and other definitional metadata. Prefer Paragraph for multi-sentence prose without markers.

## Anatomy

1. **List** — `ul.eevenkoto-list` or `ol.eevenkoto-list` (host type, markers, and item look)
2. **ListItem** — bare `li` under the host (framework prop `text`; no required item class)

## Key modifiers

### variant

| Value | Element | Marker |
| --- | --- | --- |
| `unordered` | `ul` | `disc` (default) |
| `ordered` | `ol` | `decimal` |

Tag inference: `:where(ol).eevenkoto-list` and bare `ol` under Prose are ordered without requiring `--ordered`.

## API reference

<ArgTypes of={ListStories} />

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `items` | `ListItemProps[]` | — | Rows to render. |
| `variant` | `'unordered' \| 'ordered'` | `unordered` | List kind / element. |
| `size` | `'sm' \| 'md' \| 'lg'` | `md` | Body type size. |
| `tone` | `'primary' \| 'secondary'` | `primary` | Content color. |
| `text` (item) | `string` | — | Item copy. |

```ts
export interface ListItemProps {
  text: string;
}

export interface ListProps {
  items: ListItemProps[];
  variant?: 'unordered' | 'ordered';
  size?: 'sm' | 'md' | 'lg';
  tone?: 'primary' | 'secondary';
}
```

## Framework packages

```ts
import '@eevenkoto/css/list.css';
import { renderList } from '@eevenkoto/html';

renderList({
  variant: 'unordered',
  items: [{ text: 'First step.' }, { text: 'Second step.' }],
});
```

```tsx
import { List } from '@eevenkoto/react';

<List
  variant="ordered"
  items={[{ text: 'First step.' }, { text: 'Second step.' }]}
/>
```

```vue
<script setup>
import { List } from '@eevenkoto/vue';
</script>

  <List
    variant="ordered"
    :items="[{ text: 'First step.' }, { text: 'Second step.' }]"
  />
</template>
```
