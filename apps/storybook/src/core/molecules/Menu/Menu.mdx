# Menu

Vertical **navigation** list. The host is a `<nav>` wrapping nested `<ul>` / `<li>` / `<a>`. Branches are native `<details>` / `<summary>`. The host class alone renders a scooped, raised parchment plaque and styles descendant rows — no item BEM is required for the default look. Current page uses `aria-current="page"`.

<Canvas of={MenuStories.Default} />

```html
<nav class="eevenkoto-menu" aria-label="Account">
  <ul>
    <li><a href="/profile">Profile</a></li>
    <li><a href="/library" aria-current="page">My library</a></li>
    <li><hr></li>
    <li><a href="/sign-out">Sign out</a></li>
  </ul>
</nav>
```

Menu bridges Eevenkoto’s editorial surfaces and interactive chrome:
- **Plaque & headers** echo [Statblock](?path=/docs/domain-organisms-statblock--docs): scooped outer corners, soft parchment grain, `Outfit` (`--eevenkoto-font-serif`) chapter labels in `--eevenkoto-color-content-accent`, and vertical guide rails on nested branches.
- **Rows & selection** echo [Button](?path=/docs/core-atoms-button--docs) and [LinkButton](?path=/docs/core-atoms-linkbutton--docs): directional end-scoop (`corner-shape: square scoop scoop square`), `@property`-animated `328deg` primary sheen on `aria-current="page"`, warm secondary hover, and dual-halo `:focus-visible`.

## Why to use

Account menus, view switchers, and worldbook sidebars all need a compact vertical list of destinations. Menu owns that chrome — flat rows for standalone plaques and [Popover](?path=/docs/core-atoms-popover--docs) menus, nested `group` branches for eevenko.to-style trees — without baking open/position or routing into the DS. Copy-paste HTML navigates with no app JS.

## Leading icons & sizes

Pass `icon` (from token `ICON_NAMES`) on items or groups when visual landmarks help scan dense account or tool menus. Use `size: 'sm'` (`eevenkoto-menu--sm`) for compact utility menus; `md` is the host default.

## Nested nav

Branches nest arbitrarily. Root summaries use `Outfit` serif + `content-accent` ink; deeper summaries stay `Inter` semibold so macro chapters and meso subsections mirror [Statblock](?path=/docs/domain-organisms-statblock--docs). Open branches draw a vertical guide rail along nested `<ul>` lists and swap a masked canonical chevron (`chevron-right` → `chevron-down`).

```html
<nav class="eevenkoto-menu eevenkoto-menu--embedded" aria-label="Worldbook">
  <ul>
    <li>
      <details open>
        <summary>Lajit</summary>
        <ul>
          <li><a href="#human" aria-current="page">Ihminen</a></li>
        </ul>
      </details>
    </li>
  </ul>
</nav>
```

## Locked items

`locked` adds a trailing lock Icon named by `lockedLabel` (default “Locked”). Keep `href` when signing in still navigates somewhere — the row stays a followable link in `content-secondary` ink; drop `href` and the row renders as a disabled button.

## Action escape hatch

## Inside a Popover

When `.eevenkoto-menu` is a direct child of `.eevenkoto-popover`, Menu automatically clears its outer plaque border, grain, and shadow via public override tokens so Popover owns the floating surface cleanly.

## Accessibility

- **Landmark & current page:** Host is `<nav>` (pass `label` → `aria-label` when multiple nav landmarks appear on the page); active links set `aria-current="page"`.
- **Non-color selection cue:** Selected rows combine primary fill + bold weight + thicker inline-start stroke (`--eevenkoto-line-width-md`) + scooped end silhouette.
- **Dual-halo focus:** Keyboard focus uses Eevenkoto’s dual-halo (`--eevenkoto-color-boundary-focus-outer` + `--eevenkoto-color-boundary-focus-inner`) so focus stays ≥ 3:1 against both unselected parchment and selected primary rows.
- **Reduced motion & High Contrast:** Disclosure chevrons swap SVG masks rather than relying on `transform: rotate()`, remaining accurate under `prefers-reduced-motion: reduce`. Explicit `1px solid transparent` row borders preserve hit targets in `@media (forced-colors: active)`.

## Anatomy

| Part | Role |
| --- | --- |
| Host | `<nav class="eevenkoto-menu">` |
| List | descendant `ul` / `li` (no extra class required) |
| Row | `a`, `button`, or `summary` (optional `.eevenkoto-menu__item`) |
| Current page | `aria-current="page"` on the link (or `.eevenkoto-menu__item--selected`) |
| `__header` | Static group label (`p` inside `li`, `Outfit` + accent rule) |
| `hr` | Inset rule between clusters |
| `details` | Nested branch (optional `.eevenkoto-menu__branch`) |
| `summary` | Disclosure control with masked chevron (optional `.eevenkoto-menu__summary`) |
| Nested `ul` | Indented children with inline-start guide rail |

## Framework packages

Hand-authored HTML is the reference. `renderMenu` emits the same tags from `entries`.

```ts
import '@eevenkoto/css/styles.css';
import '@eevenkoto/css/menu.css';
import { renderMenu } from '@eevenkoto/html';

renderMenu({
  label: 'Worldbook',
  entries: [
    {
      kind: 'group',
      id: 'species',
      label: 'Lajit',
      expanded: true,
      children: [
        { id: 'human', label: 'Ihminen', href: '/lajit/ihminen', selected: true },
        { id: 'troll', label: 'Peikko', href: '/lajit/peikko' },
      ],
    },
  ],
});
```

```tsx
import '@eevenkoto/css/styles.css';
import '@eevenkoto/css/menu.css';
import { Menu } from '@eevenkoto/react';

<Menu label="Worldbook" entries={entries} />
```

```vue
<script setup>
import '@eevenkoto/css/styles.css';
import '@eevenkoto/css/menu.css';
import { Menu } from '@eevenkoto/vue';
</script>

<template>
  <Menu label="Worldbook" :entries="entries" />
</template>
```

The host is `<nav>`, not `role="menu"`. Add menu semantics and arrow-key handling in the app only when you also implement the keyboard contract. Nested expand/collapse uses native `<details>`.
