# Stat

**Stat** is a numeric **display chip** for content (scores, modifiers, saves). It consumes surface / content / accent tokens — **not** the feedback domain. Interactive or status chips stay on Badge / future Chip.

Shapes map to ability roles inside AbilityScore:

| Shape | Typical role | Geometry |
| --- | --- | --- |
| `disk` | Score | Full circle |
| `arch` | Modifier | Tall figure, rounded top + scoop back-frame |
| `shield` | Save | Flat top, soft point at bottom |

```html
<span class="eevenkoto-stat eevenkoto-stat--arch eevenkoto-stat--lg">+3</span>
```

## Why to use

Ability math needs scannable glyphs with distinctive silhouettes. Stat encodes that geometry once so AbilityScore can compose three chips without one-off CSS per cell.

### Emphasis

Default borders use parchment chrome (`content-accent` → `parchment-primary`). `emphasis` (and AbilityScore `saveProficient`) switches to deep gold (`content-accent-strong` → `gold-primary-deep`) with a thicker stroke and outline.

<Canvas of={StatStories.SaveEmphasis} />

### disk

Full circle (`--eevenkoto-radius-full`). Default shape. Used for base scores.

### arch

Taller than wide, semi-circular top, light gradient fill, decorative scoop back-frame (`::before`). Primary modifier figure.

### shield

Slightly taller disk footprint with flat top corners and a soft pointed bottom (`border-radius` ellipse). Used for saves.

## Size

Shared **`sm | md | lg`** ladder. AbilityScore uses **`lg` arch** + **`sm` disk/shield**.

| Size | Approx footprint | Type |
| --- | --- | --- |
| `sm` | 3rem | `body-sm` |
| `md` | 4rem | `body-md` |
| `lg` | 5rem (arch height × 1.35) | `body-lg` |

## Anatomy

1. **Host** — `span.eevenkoto-stat`
2. **Value** — text content (no child required)
3. **Back-frame (arch only)** — `::before` scoop layer behind the face

## Accessibility

- Stat is presentational; AbilityScore supplies the accessible name via a parent `dt`.
- If used alone, wrap with visible or `aria-label` context describing what the number means.
- Prefer signed strings (`+3`, `+0`) as stored in product data — do not localize the sign in CSS.
- `emphasis` is not color-only (thicker border + outline). Forced-colors mode remaps borders to system colors / `Highlight`.

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | — | Displayed number / signed modifier. |
| `shape` | `'disk' \| 'arch' \| 'shield'` | `'disk'` | Geometry. |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Shared size ladder. |
| `emphasis` | `boolean` | `false` | Deep accent border + thicker stroke/outline. |

```ts
export type StatShape = 'disk' | 'arch' | 'shield';
export type StatSize = 'sm' | 'md' | 'lg';

export interface StatProps {
  value: string;
  shape?: StatShape;
  size?: StatSize;
  emphasis?: boolean;
}
```
