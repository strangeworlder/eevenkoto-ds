# Scroll

Portable overflow host. Default axis is horizontal (`x`) for wide tables.

<Canvas of={ScrollStories.Default} />

```html
<div class="eevenkoto-scroll eevenkoto-scroll--x">…</div>
```

### Playground

<Controls of={ScrollStories.Default} />

## When to use

Wrap content that may exceed the viewport or frame. TableShell enables Scroll by default around Table.

<DoDont
  do={
    <ul>
      <li>Use Scroll for overflow, not for decorative clipping alone.</li>
      <li>Pair with sticky index columns via TableShell.</li>
    </ul>
  }
  dont={
    <ul>
      <li>Don’t hide essential content behind scroll without a sticky cue when possible.</li>
    </ul>
  }
/>
