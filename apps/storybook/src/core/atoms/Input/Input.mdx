# Input

Single-line **control chrome** from Tier 2 **`form-input`** tokens: fill, border, focus ring, invalid paint, sizes, optional search icon. The host is `.eevenkoto-input`; the native element is `.eevenkoto-input__field` (BEM element — **not** the [Field](?path=/docs/core-molecules-field--docs) molecule).

**Input is not a form row.** It does not render a visible label, hint, or error. For those, use Field and nest Input inside it.

<Canvas of={InputStories.Default} />

```html
<span class="eevenkoto-input">
  <input class="eevenkoto-input__field" type="text" placeholder="e.g. Elowen Karth" />
</span>
```

Host alone is **md**, valid, and enabled.

## Input vs Field

| Need | Use |
| --- | --- |
| Form data entry (visible label, optional hint/error) | **[Field](?path=/docs/core-molecules-field--docs)** wrapping Input |
| Shared text-box chrome only (this page) | **Input** |
| Header / toolbar search with no room for a visible label | **Input** + `ariaLabel` |
| Accessible name for a form control | Field’s visible `label` + `htmlFor` — **not** Input `ariaLabel` |
| Error / helper copy | Field `error` / `hint` — Input only receives `invalid` + `describedBy` |

Agents: default to **Field** for anything that looks like a form. Reach for bare Input only for chrome-only controls.

## Why to use

Every product form should not invent its own text-box surface. Input owns fill, border, focus, and invalid chrome once; Field (or equivalent host markup) owns the labeling contract around it.

`invalid` paints the control and sets `aria-invalid`. In real forms, always pair with Field error text — see [Field → Error](?path=/docs/core-molecules-field--docs#error).

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `id` | `string` | — | Wire to Field `htmlFor` / `<label for>`. |
| `name` | `string` | — | Native `<input name>` for form submission. |
| `type` | `'text' \| 'search' \| 'email' \| 'password' \| 'tel' \| 'url' \| 'number'` | `'text'` (`'search'` when `search` is true) | Native `<input type>`. |
| `value` | `string` | — | Current input value. |
| `placeholder` | `string` | — | Example hint, not the accessible name. |
| `size` | `'sm' \| 'md'` | `'md'` | Control height/font scale (`control-sm` / `control-md`). |
| `ariaLabel` | `string` | — | `aria-label` when **no** visible Field label. |
| `describedBy` | `string` | — | `aria-describedby` (Field message id). |
| `invalid` | `boolean` | `false` | Invalid paint + `aria-invalid`. |
| `disabled` | `boolean` | `false` | Sets native `disabled` and opaque disabled tokens. |
| `search` | `boolean` | `false` | Pill + leading `search` Icon recipe. |
| `icon` | `string \| ReactNode` (slot in Vue/Astro) | `search` glyph when `search` is true | Custom leading icon (`icon` prop in HTML/React; `#icon` / `slot="icon"` in Vue/Astro). |
| `fullWidth` | `boolean` | `false` | Stretches wrapper to `inline-size: 100%` (`eevenkoto-input--full-width`). |

### Public CSS override tokens

| Token | Purpose |
| --- | --- |
| `--eevenkoto-input-bg` | Field wrapper background |
| `--eevenkoto-input-text` | Input text color |

| `--eevenkoto-input-border-color` | Field wrapper border color |

| `--eevenkoto-input-radius` | Corner radius (`radius-full` when `search`) |

| `--eevenkoto-input-gap` | Gap between leading icon and `<input>` |

## Framework packages

Import `@eevenkoto/css/input.css` (and `@eevenkoto/css/icon.css` when `search` is enabled or a leading icon is rendered).

```ts
import '@eevenkoto/css/styles.css';
import '@eevenkoto/css/input.css';
import '@eevenkoto/css/icon.css';
import { renderInput } from '@eevenkoto/html';

renderInput({
  search: true,
  ariaLabel: 'Search spells',
  placeholder: 'Fireball…',
});
```

```tsx
import '@eevenkoto/css/styles.css';
import '@eevenkoto/css/input.css';
import '@eevenkoto/css/icon.css';
import { Input } from '@eevenkoto/react';

<Input search ariaLabel="Search spells" placeholder="Fireball…" />
```

```vue
<script setup>
import { ref } from 'vue';
import '@eevenkoto/css/styles.css';
import '@eevenkoto/css/input.css';
import '@eevenkoto/css/icon.css';
import { Input } from '@eevenkoto/vue';

const query = ref('');
</script>

<template>
  <Input v-model:value="query" search aria-label="Search spells" placeholder="Fireball…" />
</template>
```

```astro
---
import '@eevenkoto/css/styles.css';
import '@eevenkoto/css/input.css';
import '@eevenkoto/css/icon.css';
import { Input } from '@eevenkoto/astro';
---

<Input search ariaLabel="Search spells" placeholder="Fireball…" />
```
