# Input

Single-line **control chrome** from Tier 2 **`form-input`** tokens: fill, border, focus ring, invalid paint, sizes, optional search icon. The host is `.eevenkoto-input`; the native element is `.eevenkoto-input__field` (BEM element — **not** the [Field](?path=/docs/core-molecules-field--docs) molecule).

**Input is not a form row.** It does not render a visible label, hint, or error. For those, use Field and nest Input inside it.

Host alone is **md**, valid, and enabled.

## Input vs Field

| Need | Use |
| --- | --- |
| Form data entry (visible label, optional hint/error) | **[Field](?path=/docs/core-molecules-field--docs)** wrapping Input |
| Shared text-box chrome only (this page) | **Input** |
| Header / toolbar search with no room for a visible label | **Input** + `ariaLabel` |
| Accessible name for a form control | Field’s visible `label` + `htmlFor` — **not** Input `ariaLabel` |
| Error / helper copy | Field `error` / `hint` — Input only receives `invalid` + `describedBy` |

Agents: default to **Field** for anything that looks like a form. Reach for bare Input only for chrome-only controls.

## Why to use

Every product form should not invent its own text-box surface. Input owns fill, border, focus, and invalid chrome once; Field (or equivalent host markup) owns the labeling contract around it.

## Search (chrome-only name)

Toolbar / header search with no visible Field label: `ariaLabel` names the control; placeholder stays an example query.

## Invalid chrome

`invalid` paints the control and sets `aria-invalid`. In real forms, always pair with Field error text — see [Field → Error](?path=/docs/core-molecules-field--docs#error).

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `id` | `string` | — | Wire to Field `htmlFor` / `<label for>`. |
| `ariaLabel` | `string` | — | `aria-label` when **no** visible Field label. |
| `describedBy` | `string` | — | `aria-describedby` (Field message id). |
| `invalid` | `boolean` | `false` | Invalid paint + `aria-invalid`. |
| `placeholder` | `string` | — | Example hint, not the name. |
| `search` | `boolean` | `false` | Pill + search icon recipe. |
