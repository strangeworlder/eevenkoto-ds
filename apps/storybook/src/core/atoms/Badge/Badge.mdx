# Badge

A Badge is a 1920s Playbill stamp **status or metadata** label sharing the feedback design language of [Notice](?path=/docs/core-molecules-notice--docs): sharp corners (`0px`), bold `2px` top/bottom ink rules with `1px` side hairlines, `Outfit` display type in sentence case, an optional `◆` diamond pip in its own hairline-divided stub, and warm bronze/brass `neutral` accents. Interactive filter chips belong to **`control`** ([Chip](?path=/docs/core-atoms-chip--docs)). Unlabeled tree pips are [StatusDot](?path=/docs/core-atoms-statusdot--docs).

<Canvas of={BadgeStories.Default} />

```html
<span class="eevenkoto-badge">
  <span class="eevenkoto-badge__label">Neutral</span>
</span>
```

Host alone is **subtle** + **neutral** + **md**. Minimal non-defaults: `eevenkoto-badge eevenkoto-badge--success`, or `eevenkoto-badge eevenkoto-badge--solid` (solid + neutral). Framework helpers still emit the full modifier set.

## Why to use

Status and taxonomy need a compact, scannable marker beside content — readiness, severity, membership — without looking like a click target. Badge is that non-interactive chip so metadata stays visible without competing with Buttons or filters.

## Intent → hue

| Intent | Hue (Tier 1) | Notes |
| --- | --- | --- |
| `neutral` | parchment | Live parchment primitives |
| `info` | turquoise | Live |
| `success` | green | **Placeholder** — finalize pigment |
| `caution` | orange | **Placeholder** — finalize pigment |
| `critical` | crimson | **Placeholder** — finalize pigment |
| `admin` | purple | **Placeholder** — finalize pigment |

Subtle fills use **`color-mix` in Tier 2** over `*-state` (P9). Badge variants set public `--eevenkoto-badge-*` overrides to `--eevenkoto-color-feedback-*`; private `--_eevenkoto-badge-*` bridges on the host resolve them.

## Variants

### subtle (default)

Soft tinted fill + saturated text + soft border. Host alone is subtle + neutral; add an intent class only when needed (`eevenkoto-badge eevenkoto-badge--success`).

<Canvas of={BadgeStories.SubtleMatrix} />

### solid

Emphatic fill + on-fill ink. `eevenkoto-badge--solid` alone is solid + neutral; pair with an intent for other hues.

<Canvas of={BadgeStories.SolidMatrix} />

### outline

Transparent fill; stroke and text from the subtle tuple.

<Canvas of={BadgeStories.OutlineMatrix} />

## Size

Shared **`sm | md | lg`** ladder → `--eevenkoto-font-size-control-*` (same as Button / Paragraph).

## Stamp indicator

Pass `dot` (`true`) to place an Art Deco `◆` diamond pip in a hairline-divided stub before the label, mirroring the vignette column of [Notice](?path=/docs/core-molecules-notice--docs).

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `label` | `string` | — | Visible text (sentence case). |
| `variant` | `'subtle' \| 'solid' \| 'outline'` | `'subtle'` | Surface recipe. |
| `intent` | `'neutral' \| 'info' \| 'success' \| 'caution' \| 'critical' \| 'admin'` | `'neutral'` | Feedback intent. |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Shared size ladder. |
| `dot` | `boolean` | `false` | Art Deco diamond pip (`__dot`) with vertical hairline divider. |

### Type definitions

```ts
export type BadgeVariant = 'subtle' | 'solid' | 'outline';
export type BadgeSize = 'sm' | 'md' | 'lg';
export type BadgeIntent =
  | 'neutral'
  | 'info'
  | 'success'
  | 'caution'
  | 'critical'
  | 'admin';

export interface BadgeProps {
  label: string;
  variant?: BadgeVariant;
  intent?: BadgeIntent;
  size?: BadgeSize;
  dot?: boolean;
}
```

## Framework packages

HTML is the reference implementation. React, Vue, and Astro are thin wrappers over the same BEM classes from `@eevenkoto/core`.

```bash
npm install @eevenkoto/css @eevenkoto/html
# or @eevenkoto/react / @eevenkoto/vue / @eevenkoto/astro
```

```ts
import '@eevenkoto/css/styles.css';
import '@eevenkoto/css/badge.css';
import { renderBadge } from '@eevenkoto/html';

document.body.innerHTML = renderBadge({
  label: 'Neutral',
});
```

```tsx
import '@eevenkoto/css/styles.css';
import '@eevenkoto/css/badge.css';
import { Badge } from '@eevenkoto/react';

<Badge intent="success" label="Ready" dot />
```

```vue
<script setup>
import '@eevenkoto/css/styles.css';
import '@eevenkoto/css/badge.css';
import { Badge } from '@eevenkoto/vue';
</script>

<template>
  <Badge intent="success" label="Ready" :dot="true" />
</template>
```

```astro
---
import '@eevenkoto/css/styles.css';
import '@eevenkoto/css/badge.css';
import { Badge } from '@eevenkoto/astro';
```
