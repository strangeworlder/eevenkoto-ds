# Badge

A Badge is a compact **status or metadata** label. It consumes the Tier 2 **`feedback`** domain. Interactive filter chips belong to **`control`** and ship later as Chip (P1 = Badge now, Chip later).

<Canvas of={BadgeStories.Default} />

```html
<span class="eevenkoto-badge">
  <span class="eevenkoto-badge__label">Neutral</span>
</span>
```

Host alone is **subtle** + **neutral** + **md** + **pill**. Minimal non-defaults: `eevenkoto-badge eevenkoto-badge--success`, or `eevenkoto-badge eevenkoto-badge--solid` (solid + neutral). Framework helpers still emit the full modifier set.

### Playground

<Controls of={BadgeStories.Default} />

## Why to use

Use Badge when you need a short, scannable status or taxonomy marker next to content — readiness, severity, membership metadata — without implying a click target.

## When to use

<DoDont

      <li>Don’t use ALL CAPS — sentence case + bold (P5).</li>

## Intent → hue

| Intent | Hue (Tier 1) | Notes |
| --- | --- | --- |
| `neutral` | parchment | Live parchment primitives |
| `info` | turquoise | Live |
| `success` | green | **Placeholder** — finalize pigment |
| `caution` | orange | **Placeholder** — finalize pigment |
| `critical` | crimson | **Placeholder** — finalize pigment |
| `admin` | purple | **Placeholder** — finalize pigment |

Subtle fills use **`color-mix` in Tier 2** over `*-state` (P9). Badge variants set public `--eevenkoto-badge-*` overrides to `--eevenkoto-color-feedback-*`; private `--_eevenkoto-badge-*` bridges on the host resolve them.

## Variants

### subtle (default)

Soft tinted fill + saturated text + soft border. Host alone is subtle + neutral; add an intent class only when needed (`eevenkoto-badge eevenkoto-badge--success`).

<Canvas of={BadgeStories.SubtleMatrix} />

### solid

Emphatic fill + on-fill ink. `eevenkoto-badge--solid` alone is solid + neutral; pair with an intent for other hues.

<Canvas of={BadgeStories.SolidMatrix} />

### outline

Transparent fill; stroke and text from the subtle tuple.

<Canvas of={BadgeStories.OutlineMatrix} />

## Shape

| Value | Radius token |
| --- | --- |
| `pill` (default) | `--eevenkoto-radius-full` |
| `rounded` | `--eevenkoto-radius-sm` |

Do not hard-code `9999px` in the component — change the metric token if the pill recipe needs tuning.

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `label` | `string` | — | Visible text (sentence case). |
| `variant` | `'subtle' \| 'solid' \| 'outline'` | `'subtle'` | Surface recipe. |
| `intent` | `'neutral' \| 'info' \| 'success' \| 'caution' \| 'critical' \| 'admin'` | `'neutral'` | Feedback intent. |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Shared size ladder. |
| `shape` | `'pill' \| 'rounded'` | `'pill'` | Corner treatment. |
| `dot` | `boolean` | `false` | Status dot (`__dot`). |

### Type definitions

```ts
export type BadgeVariant = 'subtle' | 'solid' | 'outline';
export type BadgeSize = 'sm' | 'md' | 'lg';
export type BadgeShape = 'pill' | 'rounded';
export type BadgeIntent =
  | 'neutral'
  | 'info'
  | 'success'
  | 'caution'
  | 'critical'
  | 'admin';

export interface BadgeProps {
  label: string;
  variant?: BadgeVariant;
  intent?: BadgeIntent;
  size?: BadgeSize;
  shape?: BadgeShape;
  dot?: boolean;
}
```

## Framework packages

HTML is the reference implementation. React and Vue are thin wrappers over the same BEM classes from `@eevenkoto/core`.

```bash
npm install @eevenkoto/css @eevenkoto/html
# or
npm install @eevenkoto/css @eevenkoto/react
npm install @eevenkoto/css @eevenkoto/vue
```

```ts
import '@eevenkoto/css/styles.css';
import '@eevenkoto/css/badge.css';
import { renderBadge } from '@eevenkoto/html';

document.body.innerHTML = renderBadge({
  label: 'Neutral',
});
```

```tsx
import '@eevenkoto/css/styles.css';
import '@eevenkoto/css/badge.css';
import { Badge } from '@eevenkoto/react';

<Badge label="Neutral" />
<Badge intent="success" label="Ready" dot />
```

```vue
<script setup>
import '@eevenkoto/css/styles.css';
import '@eevenkoto/css/badge.css';
import { Badge } from '@eevenkoto/vue';
</script>

<template>
  <Badge label="Neutral" />
  <Badge intent="success" label="Ready" :dot="true" />
</template>
```
