# Toast

A lightweight, accessible **floating feedback notification** atom. Host alone is **subtle**, **neutral**, **inline**, and **visible**.

<Canvas of={ToastStories.Default} />

```html
<div class="eevenkoto-toast" role="status" aria-live="polite">
  <span class="eevenkoto-toast__icon" aria-hidden="true">
    <svg class="eevenkoto-icon" ...></svg>
  </span>
  <span class="eevenkoto-toast__text">Asetukset tallennettu onnistuneesti.</span>
</div>
```

## Why to use

Interactive tools, workshops, and content authoring flows require immediate, unobtrusive confirmation after actions like copying to clipboard, auto-saving, or toggling state. Toast encapsulates the visual presentation, icon mapping, accessible ARIA roles, and motion transitions without coupling you to a complex singleton runtime.

## When to use

<DoDont

## Intents (Subtle)

Subtle toasts use raised surfaces with semantic border accents and icon fills. Suitable for most background feedback.

<Canvas of={ToastStories.Intents} />

## Intents (Solid)

Solid toasts use saturated semantic backgrounds. Best reserved for high-contrast alerts or important notifications.

<Canvas of={ToastStories.Solid} />

## Fixed Placement

Toasts can be rendered inline or anchored using viewport placement modifiers:
- `fixed-bottom-right`: standard desktop desktop floating toast.
- `fixed-bottom-center`: mobile-friendly bottom banner placement.

<Canvas of={ToastStories.FixedPlacement} />

## Architecture & State Management

Eevenkoto is a content design system, not an opinionated full-stack application framework:
- The **Toast atom** is strictly a presentation and accessibility component (`role="status"` / `role="alert"`).
- Dismiss timers, queueing, stacking, and portal mounting are managed by the host application or organism (such as `EquipmentWorkshop`).
- Use CSS class `.eevenkoto-toast--hidden` (or `visible={false}`) to trigger the slide-and-fade exit transition.

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `text` | `string` | — | Toast message content. |
| `intent` | `'neutral' \| 'info' \| 'success' \| 'caution' \| 'critical' \| 'admin'` | `'neutral'` | Semantic feedback intent and default icon. |
| `variant` | `'subtle' \| 'solid'` | `'subtle'` | Fill intensity variant. |
| `placement` | `'inline' \| 'fixed-bottom-right' \| 'fixed-bottom-center'` | `'inline'` | Positioning strategy. |
| `visible` | `boolean` | `true` | Visibility state for entry/exit transitions. |
| `icon` | `IconName \| false` | *intent default* | Optional icon override, or `false` to omit icon. |

## Framework packages

### HTML
```ts
import '@eevenkoto/css/toast.css';
import '@eevenkoto/css/icon.css';
import { renderToast } from '@eevenkoto/html';

const html = renderToast({
  text: 'Varustetiedot kopioitu!',
  intent: 'success',
  placement: 'fixed-bottom-right',
});
```

### React
```tsx
import '@eevenkoto/css/toast.css';
import '@eevenkoto/css/icon.css';
import { Toast } from '@eevenkoto/react';

<Toast
  text="Varustetiedot kopioitu!"
  intent="success"
  placement="fixed-bottom-right"
  visible={showToast}
/>
```

### Vue
```html
<script setup>
import '@eevenkoto/css/toast.css';
import '@eevenkoto/css/icon.css';
import { Toast } from '@eevenkoto/vue';
</script>

<template>
  <Toast
    text="Varustetiedot kopioitu!"
    intent="success"
    placement="fixed-bottom-right"
    :visible="showToast"
  />
</template>
```
