# Chip

An interactive **filter or role** chip. Consumes Tier 2 **`control`** (not feedback). Host alone is **unselected** + **md**. Selected is `--selected`. Renders as `<button>` or `<a href>`.

<Canvas of={ChipStories.Default} />

```html
<button type="button" class="eevenkoto-chip">Seuraaja</button>
```

### Playground

<Controls of={ChipStories.Default} />

## Why to use

Dev role switchers and small exclusive tags need a clickable chip that is not a Badge (feedback, non-interactive) and not a full Button. Chip is that control so eevenko.to can drop `.role-chip` / `.dev-chip`.

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `label` | `string` | — | Visible text. |
| `selected` | `boolean` | `false` | Pressed / current. |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Shared control ladder. |
| `href` | `string` | — | When set, renders as `<a>`. |
| `disabled` | `boolean` | `false` | Non-interactive (opaque disabled tokens). |
