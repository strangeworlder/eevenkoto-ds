# Caption

Caption styles short supporting or metadata text with `--eevenkoto-font-size-caption`.

<Canvas of={CaptionStories.Default} />

```html
<p class="eevenkoto-caption eevenkoto-caption--secondary">Updated 2 hours ago</p>
```

### Playground

<Controls of={CaptionStories.Default} />

## Why to use

Captions keep timestamps, helper hints, and field metadata visually quieter than body copy without inventing a one-off rem value.

## When to use

Use Caption under form fields, on cards, or beside status metadata. Prefer Paragraph for multi-sentence prose and Heading for titles.

<DoDont

## Key modifiers

### tone

| Value | Default | Content color |
| --- | --- | --- |
| `secondary` | Yes | `--eevenkoto-color-content-secondary` |
| `primary` | No | `--eevenkoto-color-content-primary` |
