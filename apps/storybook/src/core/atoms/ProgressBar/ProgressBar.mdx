# ProgressBar

A thin `role="progressbar"` indicator. Hidden until `active`; **indeterminate** unless `value` is given. With `fixed` it becomes a `0.3rem` bar at the viewport top (`--eevenkoto-z-toast`).

## Why to use

Shared motion, `prefers-reduced-motion` fallback (static 65% fill), forced-colors and print behavior for page-transition and upload feedback.

## When to use

- Use `fixed` + `tone="accent"` or `"primary"` for page-navigation progress; toggle `active` from your router.
- Use `value` for known-length work like uploads.
- Don't use it for form-step position — use [Stepper](?path=/docs/core-molecules-stepper--docs).

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `id` | `string` | — | DOM id. |
| `active` | `boolean` | `false` | Visible; sets `aria-busy`. Otherwise `aria-hidden`. |
| `tone` | `'primary' \| 'accent'` | `'primary'` | Turquoise or gold fill. |
| `fixed` | `boolean` | `false` | Pin to viewport top. |
| `label` | `string` | `'Loading'` | Accessible name. |
| `value` | `number` | — | Determinate 0–100 (clamped). |
