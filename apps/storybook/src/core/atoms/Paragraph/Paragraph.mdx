# Paragraph

Paragraph styles body copy using Tier 2 `--eevenkoto-font-size-body-*` tokens (never raw `sm`/`md`/`lg` scale steps).

<Canvas of={ParagraphStories.Default} />

```html
<p class="eevenkoto-paragraph">
  …
</p>
```

The base class alone is the default (`body-md` / primary). Size and tone modifiers are opt-in. Framework helpers still emit explicit `--md` / `--primary` for the component API.

### Playground

<Controls of={ParagraphStories.Default} />

## Why to use

Consistent body type keeps reading rhythm stable across pages and themes. Semantic sizes let density or theme remaps change roles without renaming the rem ladder.

## When to use

Use Paragraph for multi-sentence body copy. Prefer Heading for titles and Caption for short metadata.

<DoDont
  do={
    <ul>
      <li>Use Paragraph for body copy and supporting prose.</li>
      <li>Pick size from body roles (`sm` / `md` / `lg`).</li>
      <li>Use Secondary tone for de-emphasized supporting paragraphs.</li>
    </ul>
  }
  dont={
    <ul>
      <li>Don’t use Paragraph as a page or section title — use Heading.</li>
      <li>Don’t use Paragraph for one-line metadata — use Caption.</li>
      <li>Don’t hard-code rem or Tier 1 `--eevenkoto-font-size-md` in local CSS.</li>
    </ul>
  }
/>

## Key modifiers

### size

| Value | Token |
| --- | --- |
| `sm` | `--eevenkoto-font-size-body-sm` |
| `md` | `--eevenkoto-font-size-body-md` |
| `lg` | `--eevenkoto-font-size-body-lg` |

<Canvas of={ParagraphStories.SizeComparison} />

### tone

| Value | Content color |
| --- | --- |
| `primary` | `--eevenkoto-color-content-primary` |
| `secondary` | `--eevenkoto-color-content-secondary` |
