# TableCell

`th` / `td` atom with kinds `index`, `numeric`, and `text`. The Table molecule composes these cells.

<Canvas of={TableCellStories.Default} />

```html
<td class="eevenkoto-table-cell">Body cell</td>
```

Host alone is the **text** kind (`min-width`, start-aligned). Add `--index` / `--numeric` only when needed; `--text` remains a valid alias.

## Kinds

| Kind | Role |
| --- | --- |
| `index` | Level, die face, row key — narrow, tabular |
| `numeric` | Compact digits; angled head label when used as numeric header in Table `--numeric` |
| `text` | Descriptive cells — take remaining width |
