# TableCell

`th` / `td` atom with kinds `index`, `numeric`, and `text`. The Table molecule composes these cells.

<Canvas of={TableCellStories.Default} />

```html
<td class="eevenkoto-table-cell">Body cell</td>
```

Host alone is the **text** kind (`min-width`, start-aligned). Add `--index` / `--numeric` only when needed; `--text` remains a valid alias.

Inside a [Table](?path=/docs/core-molecules-table--docs) the base class is redundant — the host styles bare `th` / `td`, so `<td>Body cell</td>` is enough and only kinds need a class. Reach for `eevenkoto-table-cell` when the cell sits in a table that does **not** carry the host class. The framework `TableCell` takes `inTable` to switch between the two class strings; Table sets it for you.

## Why to use

Tabular columns need distinct alignment and width roles (`index`, `numeric`, `text`) plus optional angled numeric headers without repeating cell CSS across custom tables.

## When to use

Compose `TableCell` automatically via [Table](?path=/docs/core-molecules-table--docs), or use `TableCell` directly when building custom `<thead>` / `<tbody>` rows (pass `inTable` under `.eevenkoto-table` to omit redundant default classes).

## Kinds

| Kind | Role |
| --- | --- |
| `index` | Level, die face, row key — narrow, tabular |
| `numeric` | Compact digits; angled head label when used as numeric header in Table `--numeric` |
| `text` | Descriptive cells — take remaining width |

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `kind` | `'index' \| 'numeric' \| 'text'` | `'text'` | Column role (`eevenkoto-table-cell--*`). |
| `inTable` | `boolean` | `false` | Omits redundant host/`--text` classes when nested under `.eevenkoto-table`. |
| `text` | `string` | — | Plain-text cell copy (`children` / default slot in React, Vue, and Astro). |
| `html` | `string` | — | Trusted pre-rendered inline HTML (takes precedence over `text`). |
| `header` | `boolean` | `false` | Renders `<th>` instead of `<td>`. |
| `scope` | `'col' \| 'row' \| 'colgroup' \| 'rowgroup'` | — | `scope` attribute when `header` is `true`. |
| `colSpan` | `number` | — | `colspan` attribute. |
| `rowSpan` | `number` | — | `rowspan` attribute. |
| `angled` | `boolean` | `false` | Wraps header label for angled numeric heads (`numeric` + `header`). |
| `attributes` | `TableElementAttributes` | — | Extra HTML/data/ARIA attributes on `<th>` / `<td>`. |
| `tabIndex` | `number` | — | `tabindex` attribute (HTML/Astro; React/Vue via host attributes). |
| `id` | `string` | — | Cell element `id` (React, Vue, and Astro HTML attributes, or `attributes.id` in HTML). |

## Framework packages

HTML uses a `text` (or `html`) prop. React, Vue, and Astro use children / the default slot.

```ts
import '@eevenkoto/css/styles.css';
import '@eevenkoto/css/table-cell.css';
import { renderTableCell } from '@eevenkoto/html';

renderTableCell({ text: 'Body cell' });
renderTableCell({ kind: 'numeric', header: true, scope: 'col', text: 'Lvl', angled: true });
```

```tsx
import '@eevenkoto/css/styles.css';
import '@eevenkoto/css/table-cell.css';
import { TableCell } from '@eevenkoto/react';

<tr>
  <TableCell header scope="col" kind="numeric" angled>
    Lvl
  </TableCell>
  <TableCell>Body cell</TableCell>
</tr>
```

```vue
<script setup>
import '@eevenkoto/css/styles.css';
import '@eevenkoto/css/table-cell.css';
import { TableCell } from '@eevenkoto/vue';
</script>

<template>
  <tr>
    <TableCell header scope="col" kind="numeric" angled>Lvl</TableCell>
    <TableCell>Body cell</TableCell>
  </tr>
</template>
```

```astro
---
import '@eevenkoto/css/styles.css';
import '@eevenkoto/css/table-cell.css';
import { TableCell } from '@eevenkoto/astro';
---

  <TableCell header scope="col" kind="numeric" angled>Lvl</TableCell>

```
