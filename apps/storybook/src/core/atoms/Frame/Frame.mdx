# Frame

Portable bordered surface (“chart in a box”). TableShell uses Frame by default; Frame is reusable beyond tables.

<Canvas of={FrameStories.Default} />

```html
<div class="eevenkoto-frame">…</div>
```

### Playground

<Controls of={FrameStories.Default} />

## When to use

Wrap dense charts, token panels, or any content that should read as a contained rulebook panel. Prefer bare layout when the page canvas is enough.

<DoDont
  do={
    <ul>
      <li>Use Frame for portable bordered hosts.</li>
      <li>Compose Frame inside TableShell for rulebook charts.</li>
    </ul>
  }
  dont={
    <ul>
      <li>Don’t nest Frames for decoration alone.</li>
      <li>Don’t put product vocabulary into Frame APIs.</li>
    </ul>
  }
/>
