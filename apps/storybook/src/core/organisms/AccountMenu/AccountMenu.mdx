# AccountMenu

Account entry point. Signed out it renders a full-width secondary sign-in [LinkButton](?path=/docs/core-atoms-linkbutton--docs) with a leading `user` [Icon](?path=/docs/core-atoms-icon--docs). Signed in it renders a trigger (small [Avatar](?path=/docs/core-atoms-avatar--docs), single-line name, tier [Badge](?path=/docs/core-atoms-badge--docs), rotating chevron) and a trigger-width [Popover](?path=/docs/core-atoms-popover--docs) with a profile summary, an embedded [Menu](?path=/docs/core-molecules-menu--docs) and an optional footer.

## Why to use

Encodes the trigger's `aria-haspopup` / `aria-expanded` wiring, ellipsis for long names, and destructive sign-out styling (`tone: 'destructive'` on the Menu entry) in one place.

## When to use

- Use once per app, typically in a sidebar or header.
- Toggle `open` from your own handler (`onToggle` in React, `toggle` event in Vue); close on outside click and Escape yourself.
- Don't use it for generic dropdowns — compose [Popover](?path=/docs/core-atoms-popover--docs) with [Menu](?path=/docs/core-molecules-menu--docs).

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `authenticated` | `boolean` | — | Signed-in state. |
| `loginHref` / `loginLabel` | `string` | `'#login'` / `'Sign in'` | Signed-out link. |
| `userName` / `userEmail` | `string` | — | Identity (email omitted when empty). |
| `avatarSrc` | `string` | — | Avatar image. |
| `tierLabel` / `tierIntent` | `string` / `BadgeIntent` | — / `'neutral'` | Tier badge. |
| `menuLabel` / `popoverLabel` | `string` | `'Account menu'` / `'Account'` | Accessible names. |
| `entries` | `MenuEntry[]` | — | Popover menu entries. |
| `open` | `boolean` | `false` | Popover expanded. |
| `footer` | slot / prop | — | Popover footer. |
| `id` | `string` | — | Host element `id` (also seeds popover `aria-controls` id). |

## Framework packages

`account-menu.css` imports `avatar.css`, `badge.css`, `icon.css`, `link-button.css`, `popover.css`, and `menu.css` automatically.

```ts
import '@eevenkoto/css/styles.css';
import '@eevenkoto/css/account-menu.css';
import { renderAccountMenu } from '@eevenkoto/html';

renderAccountMenu({ authenticated: false, loginLabel: 'Sign in' });
```

```tsx
import { useState } from 'react';
import '@eevenkoto/css/styles.css';
import '@eevenkoto/css/account-menu.css';
import { AccountMenu } from '@eevenkoto/react';

export function HeaderAccount() {
  const [open, setOpen] = useState(false);
  return (
    <AccountMenu
      authenticated
      userName="Aino"
      open={open}
      onToggle={setOpen}
      entries={[{ id: 'settings', label: 'Asetukset', href: '/tili' }]}
    />
  );
}
```

```vue
<script setup>
import { ref } from 'vue';
import '@eevenkoto/css/styles.css';
import '@eevenkoto/css/account-menu.css';
import { AccountMenu } from '@eevenkoto/vue';

const open = ref(false);
const entries = [{ id: 'settings', label: 'Asetukset', href: '/tili' }];
</script>

<template>
  <AccountMenu
    :authenticated="true"
    user-name="Aino"
    :open="open"
    :entries="entries"
    @toggle="open = !open"
  />
</template>
```
