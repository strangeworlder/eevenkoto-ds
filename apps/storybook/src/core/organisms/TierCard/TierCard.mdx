# TierCard

A comparison card for membership or pricing tiers. It composes [Card](?path=/docs/core-molecules-card--docs) (elevated; `featured` → accent outline; `current` → focus ring), a [Badge](?path=/docs/core-atoms-badge--docs), a checklist [List](?path=/docs/core-molecules-list--docs) and a full-width [LinkButton](?path=/docs/core-atoms-linkbutton--docs). The CTA sits at the bottom so cards in a grid align.

```html
  <header class="eevenkoto-tier-card__header">

      <li class="eevenkoto-list__item eevenkoto-list__item--included">Kaikki säännöt</li>
    </ul>
  </div>
  <footer class="eevenkoto-tier-card__footer">
    <a class="eevenkoto-link-button eevenkoto-link-button--full-width" href="/tilaa">Valitse taso</a>
  </footer>
</article>
```

## Why to use

Tier comparison needs consistent structure, a non-color cue for excluded features (visually hidden text plus strikethrough), and a clear active-tier state.

## When to use

- Use in a grid of 2–5 tiers.
- Set `current` on the user's active tier and `featured` on the recommended one (they may both apply).
- Don't use it for generic content cards — use [Card](?path=/docs/core-molecules-card--docs).

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `name` | `string` | — | Tier name. |
| `nameLevel` | `2 \| 3` | `2` | Heading level. |
| `badge` | `BadgeProps` | — | Header pill (shape defaults to `pill`). |
| `price` / `period` | `string` | — | Price and cadence. |
| `description` / `descriptionHtml` | `string` | — | Summary copy. |
| `features` | `ListItemProps[]` | — | Checklist items (`included` / `accent` / `excluded`). |
| `featured` / `current` | `boolean` | `false` | Accent outline / active-tier ring. |
| `cta` | `LinkButtonProps` | — | Full-width CTA (or use `footer`). |
| `id` | `string` | — | Host `<article id>`. |

### Public CSS override tokens

| Token | Purpose |
| --- | --- |
| `--eevenkoto-tier-card-name-color` | Tier heading ink (`content-primary`) |
| `--eevenkoto-tier-card-price-color` | Price numeral ink (`content-primary`) |
| `--eevenkoto-tier-card-muted-color` | Billing period and description ink (`content-secondary`) |

## Framework packages

`tier-card.css` imports `card.css`, `badge.css`, `list.css`, and `link-button.css` automatically.

```ts
import '@eevenkoto/css/styles.css';
import '@eevenkoto/css/tier-card.css';
import { renderTierCard } from '@eevenkoto/html';

renderTierCard({
  name: 'Patron',
  price: '5 €',
  period: '/ mo',
  features: [{ text: 'Early access' }],
});
```

```tsx
import '@eevenkoto/css/styles.css';
import '@eevenkoto/css/tier-card.css';
import { TierCard } from '@eevenkoto/react';

<TierCard
  name="Patron"
  price="5 €"
  period="/ mo"
  features={[{ text: 'Early access' }]}
  featured
/>
```

```vue
<script setup>
import '@eevenkoto/css/styles.css';
import '@eevenkoto/css/tier-card.css';
import { TierCard } from '@eevenkoto/vue';

const features = [{ text: 'Early access' }];
</script>

<template>
  <TierCard name="Patron" price="5 €" period="/ mo" :features="features" :featured="true" />
</template>
```
